# 任务

根据场景提取结果、分集剧情依据、角色和道具，设计后续生图与视频可复用的无人物场景三视图。

# 输入

标题：{{title}}

当前场景提取结果：
{{layout_extracts}}

分集剧情依据：
{{episode_stories}}

导演前期约束：
{{director_prep}}

角色：
{{roles}}

道具：
{{props}}

场景画风设计要求：{{layout_design_style_prompt}}

# 要求

- 合并相同地点，不要为同一个空间反复生成多个场景。
- 优先覆盖 `layout_extract` 中的场景；如必须补充提取遗漏的关键空间，应保证它确实出现在分集剧情依据中。
- 分集剧情依据来自 `script_novel_extract`，它是唯一剧情依据，不要假设还有额外压缩剧本。
- 导演前期约束用于保持空间结构、场景氛围和不能变的事实；如果它与分集剧情依据或完整正文继承信息冲突，以剧本事实为准。
- `name` 使用短名称，例如「雨夜办公室」「会议室」。
- `desc` 写空间结构、光线、材质、气氛和可复用的视觉特征。
- `prompt` 直接用于无人物场景三视图生成，必须写成完整生图提示词，不要写成地点摘要。每个 `prompt` 建议 260-460 个中文字符。
- `prompt` 必须明确“无人物场景三视图设定板”，并要求输出一张横向 16:9 资产设定图，画面分成三个并列视图：左侧为顶视平面/空间动线图，中间为正向主视/入口朝向立面图，右侧为侧向或 45 度透视图。三个视图必须表现同一个空间、同一套固定结构、同一光源方向和同一材质设定，不能变成三个不同场景。
- 顶视平面图必须交代入口、窗/墙/柱/地面边界、主要家具或固定装置、角色可站位区域、摄影机可站位区域、剧情关键道具可摆放位置和行动动线。
- 正向主视图必须交代空间高度、前中后景层次、背景锚点、主视觉焦点、主要光源、墙面/天花/地面关系、重要装置和可供视频镜头复用的稳定构图。
- 侧向或 45 度透视图必须交代空间纵深、遮挡关系、可绕行路径、道具与人物站位的前后关系、材质厚度、反射/阴影和空气粒子状态。
- `prompt` 必须包含：画面风格要求、地点类型、时代/地域质感、昼夜/天气、空间结构、入口/窗/墙/地面/天花板关系、主要家具或固定装置、剧情关键道具可摆放的位置、材质纹理、色彩关系、主光来源、辅光/轮廓光/反射、阴影形状、空气粒子或环境状态、9:16 短剧镜头可取景区域。
- 场景三视图是后续故事板和视频生成的空间基准，必须让摄影指导能从 `prompt` 中判断角色后续可以站在哪些区域、道具可以放在哪些表面、镜头可以从哪些方向拍，而不是只生成一个固定角度空镜。
- 场景应为空场景，不要出现人物、背影、手、剪影、人群、照片里的真人、海报人物、字幕、水印、文字标识。公司 logo、门牌、屏幕文字等如非剧情必要，不要生成可读文字。
- 不要只写“高级办公室”“现代会议室”“阴森山洞”这类概念词；必须写出可复现的空间事实，例如桌椅数量、玻璃墙位置、窗外景别、地面材质、灯具形状、雨痕、灰尘、碎石、雾气、反光。
- 如果同一场景在多集复用，`prompt` 要优先写稳定空间特征，剧情造成的临时变化只写为可替换状态，不要让场景资产绑定某一个一次性动作。
- 不要把三视图写成三张独立图片；必须是一张图内三个并列视图，保持统一比例、统一美术风格、统一空间尺度。允许少量不可读的小标签或分区标题，但不要出现剧情文字、字幕、水印、logo、项目名、文件名或 ID。
- `episode_keys` 标记该场景出现在哪些集。
- 输出必须符合调用方提供的 JSON schema。

# `prompt` 示例

现实场景示例：

```text
真人电影质感，无人物场景三视图设定板，雨夜现代写字楼董事会议室，一张横向16:9资产图内并列三格。左侧顶视平面图标明短边入口、长会议桌、十二把黑色皮椅、落地玻璃墙、投影幕、玻璃白板、可放合同/录音笔的桌面区域和角色可站位动线；中间正向主视从入口朝投影幕方向展示桌面前景、投影幕中景、雨夜城市霓虹背景；右侧45度侧向透视展示玻璃墙雨痕、桌椅纵深、顶灯和窗外蓝色轮廓光。冷白顶灯与投影光为主光，桌面有细微反射和咖啡杯水渍，真实玻璃、金属、皮革和木纹材质，无人物、无手、无可读文字、无字幕水印。
```

```text
爱死机风格写实CG，无人物场景三视图设定板，暴雨夜的破碎仙山浮岛，一张横向16:9资产图内并列三格。左侧顶视平面图标明裂开的悬浮黑石边缘、断裂石阶、可插剑的黑色石台、远处断裂山门、角色半跪区域和绕行路径；中间正向主视展示低角度望向断裂山门的空间锚点、云层残月和多层浮岛轮廓；右侧45度侧向透视展示浮岛高度差、漂浮碎石、石台遮挡关系、雨线与雾气穿过空间的层次。冷银月光从云缝垂直劈下，黑石表面有水光反射、碎石粉尘和白色水汽；无人物、无生物、无文字标识、无字幕水印。
```
