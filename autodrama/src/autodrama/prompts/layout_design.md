# 任务

根据场景提取结果、分集剧情依据、角色和道具，设计后续生图与视频可复用的无人物场景。

# 输入

标题：{{title}}

当前场景提取结果：
{{layout_extracts}}

分集剧情依据：
{{episode_stories}}

导演前期约束：
{{director_prep}}

角色：
{{roles}}

道具：
{{props}}

场景画风设计要求：{{layout_design_style_prompt}}

# 要求

- 合并相同地点，不要为同一个空间反复生成多个场景。
- 优先覆盖 `layout_extract` 中的场景；如必须补充提取遗漏的关键空间，应保证它确实出现在分集剧情依据中。
- 分集剧情依据来自 `script_novel_extract`，它是唯一剧情依据，不要假设还有额外压缩剧本。
- 导演前期约束用于保持空间结构、场景氛围和不能变的事实；如果它与分集剧情依据或完整正文继承信息冲突，以剧本事实为准。
- `name` 使用短名称，例如「雨夜办公室」「会议室」。
- `desc` 写空间结构、光线、材质、气氛和可复用的视觉特征。
- `prompt` 直接用于无人物场景图生成，必须写成完整生图提示词，不要写成地点摘要。每个 `prompt` 建议 180-360 个中文字符。
- `prompt` 必须明确“无人物”，并包含：画面风格要求、地点类型、时代/地域质感、昼夜/天气、空间结构、入口/窗/墙/地面/天花板关系、前景/中景/背景层次、主要家具或固定装置、剧情关键道具可摆放的位置、材质纹理、色彩关系、主光来源、辅光/轮廓光/反射、阴影形状、空气粒子或环境状态、镜头高度、镜头方向、焦段/景别、16:9 短剧构图适配。
- 场景图是后续故事板和视频生成的空间基准，必须让摄影指导能从 `prompt` 中判断相机站在哪里、朝哪里拍、角色后续可以站在哪些区域、道具可以放在哪些表面。
- 场景应为空场景，不要出现人物、背影、手、剪影、人群、照片里的真人、海报人物、字幕、水印、文字标识。公司 logo、门牌、屏幕文字等如非剧情必要，不要生成可读文字。
- 不要只写“高级办公室”“现代会议室”“阴森山洞”这类概念词；必须写出可复现的空间事实，例如桌椅数量、玻璃墙位置、窗外景别、地面材质、灯具形状、雨痕、灰尘、碎石、雾气、反光。
- 如果同一场景在多集复用，`prompt` 要优先写稳定空间特征，剧情造成的临时变化只写为可替换状态，不要让场景资产绑定某一个一次性动作。
- `episode_keys` 标记该场景出现在哪些集。
- 输出必须符合调用方提供的 JSON schema。

# `prompt` 示例

现实场景示例：

```text
真人电影质感，无人物空场景图，雨夜现代写字楼董事会议室。相机位于会议桌短边入口处，平视略低机位朝向远端投影幕，35mm 中广角；前景是深色长会议桌边缘和几把黑色皮椅，中景为投影幕、玻璃白板和可摆放合同/录音笔的桌面区域，背景是一整面落地玻璃墙，窗外城市霓虹被雨痕拉成长条反光。冷白顶灯与投影光为主光，窗外蓝色雨光形成轮廓光，桌面有细微反射和咖啡杯水渍；真实玻璃、金属、皮革和木纹材质，无人物、无手、无可读文字、无字幕水印。
```
