# 任务

根据角色设定和分集剧情依据，为每个主要角色生成稳定的人物形象设计、人物绑定物品设计，以及人物介绍视频 prompt。

# 输入

标题：{{title}}

分集剧情依据：
{{episode_stories}}

角色设定：
{{roles}}

人物设计统一风格要求：{{role_design_style_prompt}}

人物形象图视图要求：{{role_appearance_view_requirement}}

# 要求

- `role_name` 必须填写角色设定中的 `name` 原文，例如“林浩”；不要填写角色 ID、字典键、`role_林浩` 这类内部标识。
- 每个主要角色至少输出一个 `base` 形象。
- `desc` 写给人读，包含年龄感、体型、五官、气质、稳定可复用的体貌特征，不写剧情剧透。
- 人物形象设计要克制拟真度：整体画面风格可以保持项目设定的电影级写实CG质感，但人类/类人角色的脸、皮肤、毛发必须偏高质量风格化CG动漫角色，不要写成照片级真人、真实摄影人像、真实皮肤纹理、毛孔、汗渍、微血管、皮肤斑点、真实人脸扫描或可被误判为现实人物肖像的描述。
- 角色识别点优先来自脸型轮廓、眼型、眉形、发型、服装剪裁、配饰、色彩和气质的风格化组合；不要依赖真人级皮肤细节、某个现实明星脸、真实身份证照感或摄影棚人像感。
- `role_bound_props` 只列出和该角色强绑定、会影响角色识别或动作方式的主要物品，例如武器、法器、面具、戒指、包、常用工具；不要列全局剧情证物或只出现一次的普通背景物。
- 每个 `role_bound_props` 条目要写清可见特征、真实尺寸感、材质、状态、与角色整体身高或服装位置的比例关系、角色如何佩戴或使用。
- `full_body_prompt` 直接用于生成 1:2 正面全身照参考图。必须写成单人正面全身自然展示，角色从头到脚完整入画；人物脸部与皮肤必须写成风格化CG/CG动漫质感，不要写照片级真人肖像、真实摄影、真实皮肤毛孔或真实人脸细节；不要立正站立、不要证件照姿势、不要三视图、不要右侧道具设计图、不要其他人物、字幕、水印或文字标识。
- `prompt` 直接用于生成三视图 + 道具设计图，并会以 `full_body_prompt` 生成的正面全身照作为参考。设计图必须是同一张图：左侧或主体区域为同一角色正面、侧面、背面三视图，右侧为其主要绑定物品设计图。右侧道具必须直接以人物三视图为比例参照，和人物保持同一画布比例尺、同一地面基线或同一高度参照线，展示道具本体的真实大小关系、完整轮廓、结构细节和材质，不展示额外手掌、手指、手部持握姿态或其他身体部位。
- `prompt` 建议 260-520 个中文字符，必须包含：画面风格要求、人物形象图视图要求、年龄段、性别呈现、地域/时代气质、身高体型、头身比例、脸型、五官、眼神、发型发色、肤色/皮肤质感、常态表情、站姿或坐姿、双臂自然状态、基础服装、鞋履、可复用配饰、材质纹理、干净背景、光线、镜头/构图。
- `prompt` 必须明确：左侧是人物形象，右侧是主要物品设计图，右侧物品以正交或轻微透视方式单独陈列，并直接对照左侧人物身高、肩宽、腰线或脚边地面基线来体现真实比例；不要用独立刻度尺作为主要比例参照，不要用手掌、手指、手臂、持握姿态或真实身体部位作为比例参照；无其他人物、无字幕、无水印、无文字标识、无多余肢体、不要夸张畸变。
- `prompt` 必须使用更温和的角色设定图表达。即使原文有战斗、死亡、尸化、伤口、血迹、恐怖变异等信息，也要改写成低风险视觉元素：病态苍白、疲惫眼神、异化纹理、服装破损、尘土、泥污、旧污渍、暗色裂纹、非写实纹样。不要写血液、血渍、开放性伤口、内脏、断肢、写实尸体或 gore 细节；衣服上的血迹统一替换为泥土、脏污或旧污渍。
- 右侧物品比例参照必须直接使用左侧人物：例如“道具与左侧人物保持同一比例尺”“道具底部与左侧人物脚边地面线对齐”“道具高度约为左侧人物身高的三分之一”。不要写“手掌长度”“手持比例”“简化手掌轮廓”“人物持握姿态”“放置一只真实手掌”等任何手部参照，也不要把刻度尺作为主要参照。
- 对真人电影质感或爱死机写实CG风，也只保持镜头、光影、场景、材质的电影质感；人物脸部和皮肤仍必须是风格化CG/CG动漫角色，不要写真实摄影、真实皮肤纹理、毛孔汗渍、真实人脸扫描或照片级真人肖像；对 `prompt` 仍要输出三视图 + 道具设计图。
- 对 2D/3D/CG 风格角色，要严格保留对应风格，不要混入真人摄影词；如“人物形象图视图要求”要求三视图，必须明确正面、侧面、背面并排，同一身高比例和同一服装细节。
- 角色识别点必须来自稳定体貌、气质、发型、服装剪裁、配饰和色彩关系；不要把某一件临时剧情道具、伤痕、血迹、雨水、表情崩溃当作 base 形象的唯一识别点。
- `intro_video_prompt` 用于后续以设计图为参考生成角色介绍视频。风格向 Seedance 官方示例靠拢：写成一段连续自然语言，引用参考素材时使用“参考图片1”或“图片1中的人物外观”，再用 `0-2 秒：...；2-5 秒：...；5-8 秒：...。` 这样的内嵌时间段描述动作和镜头，不要写成分镜数组、分条清单或方括号标签。
- `intro_video_prompt` 必须描述：人物站在洁净、亮度适中的虚空圆台上，圆台缓慢转动；人物做几个符合身份和性格的常见动作；如有绑定物品，要展示佩戴、握持或使用方式；视频整体符合人物常见场景气质，但背景仍保持干净抽象，不出现剧情剧透。
- `intro_video_prompt` 不要出现字幕、水印、文字标识或其他人物；如需声音，只写自然环境声或衣料、道具轻响，不要额外编写对白。
- 不要混用与画面风格冲突的描述。
- 输出必须符合调用方提供的 JSON schema。

# `prompt` 示例

真人电影质感示例：

```text
真人电影质感，三视图角色设定图；干净浅灰背景，无其他人物。画面左侧为同一名二十八岁中国男性职场调查员的正面、侧面、背面三视图并排，统一身高比例、头身比例、脸型、短黑发自然侧分、深灰西装、白衬衫、黑色皮鞋和服装细节；角色身高偏高、体型清瘦但肩背挺直，脸型窄长，下颌线清晰，眉骨略高，单眼皮，眼神疲惫但冷静，肤色偏冷白，有轻微黑眼圈和真实皮肤纹理。画面右侧是他的黑色录音笔和旧合同夹设计图，两个道具与左侧三视图人物保持同一比例尺并单独陈列，合同夹按 A4 尺寸贴近人物大腿高度作为参照，录音笔按真实大小靠近合同夹边缘显示，不出现手掌、手指或持握姿态；柔和侧光，85mm 人像镜头，中性构图，真实毛发和布料褶皱，无字幕、水印、文字标识。
```

三视图风格示例：

```text
高质量三维动画质感，三视图角色设定图 / character turnaround sheet：画面左侧为同一角色正面、侧面、背面三视图并排，统一身高比例和同一服装细节，干净背景，无其他人物。二十六岁女性数据分析师，身形修长，肩颈线条利落，鹅蛋脸，细长眉，眼神冷静克制，黑色齐肩直发，低饱和蓝灰色衬衫、黑色高腰长裤、细框眼镜、银色腕表。画面右侧为银色腕表和数据平板设计图，腕表与数据平板和左侧人物保持同一比例尺，数据平板底边与左侧人物脚边地面线对齐并显示其相当于人物前臂长度的真实大小，腕表按真实大小靠近平板边缘显示，不出现手掌、手指或持握姿态；材质为动画电影级布料、金属和皮肤着色，轮廓清晰，正交设定图光线，无字幕、水印、文字标识。
```
