# 任务

根据角色设定和分集剧情依据，为每个主要角色生成稳定的人物形象设计、人物绑定物品设计，以及人物介绍视频 prompt。

# 输入

标题：{{title}}

分集剧情依据：
{{episode_stories}}

角色设定：
{{roles}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

人物形象图视图要求：{{role_appearance_view_requirement}}

# 要求

- `role_name` 必须填写角色设定中的 `name` 原文，例如“林浩”；不要填写角色 ID、字典键、`role_林浩` 这类内部标识。
- 每个主要角色至少输出一个 `base` 形象。
- `desc` 写给人读，包含年龄感、体型、五官、气质、稳定可复用的体貌特征，不写剧情剧透。
- `role_bound_props` 只列出和该角色强绑定、会影响角色识别或动作方式的主要物品，例如武器、法器、面具、戒指、包、常用工具；不要列全局剧情证物或只出现一次的普通背景物。
- 每个 `role_bound_props` 条目要写清可见特征、尺寸感、材质、状态、与角色的比例关系、角色如何佩戴或使用。
- `prompt` 直接用于生成角色设计图。设计图必须是同一张图：左侧为人物形象，右侧为其主要绑定物品设计图，并体现人物与物品的大小比例、佩戴方式、握持方式或使用方式。
- `prompt` 建议 260-520 个中文字符，必须包含：画面风格要求、人物形象图视图要求、年龄段、性别呈现、地域/时代气质、身高体型、头身比例、脸型、五官、眼神、发型发色、肤色/皮肤质感、常态表情、站姿或坐姿、手部状态、基础服装、鞋履、可复用配饰、材质纹理、干净背景、光线、镜头/构图。
- `prompt` 必须明确：左侧是人物形象，右侧是主要物品设计图，右侧物品要包含尺寸标尺感或人物持握/佩戴比例关系；无其他人物、无字幕、无水印、无文字标识、无多余肢体、不要夸张畸变。
- 对真人电影质感角色，要写真实摄影、真实皮肤纹理、自然毛发、布料褶皱、真实比例、电影感柔和布光；不要写三视图拼版。
- 对 2D/3D/CG 风格角色，要严格保留对应风格，不要混入真人摄影词；如“人物形象图视图要求”要求三视图，必须明确正面、侧面、背面并排，同一身高比例和同一服装细节。
- 角色识别点必须来自稳定体貌、气质、发型、服装剪裁、配饰和色彩关系；不要把某一件临时剧情道具、伤痕、血迹、雨水、表情崩溃当作 base 形象的唯一识别点。
- `intro_video_prompt` 用于后续以设计图为参考生成角色介绍视频。必须描述：人物站在洁净、亮度适中的虚空圆台上，圆台缓慢转动；人物做几个符合身份和性格的常见动作；如有绑定物品，要展示佩戴、握持或使用方式；视频整体符合人物常见场景气质，但背景仍保持干净抽象，不出现剧情剧透。
- `intro_video_prompt` 不要写成分镜数组，不要出现字幕、水印、文字标识或其他人物。
- 不要混用与画面风格冲突的描述。
- 输出必须符合调用方提供的 JSON schema。

# `prompt` 示例

真人电影质感示例：

```text
真人电影质感，半身或全身真人电影感角色设定图；干净浅灰背景，无其他人物。画面左侧是二十八岁中国男性职场调查员全身形象，身高偏高、体型清瘦但肩背挺直，脸型窄长，下颌线清晰，眉骨略高，单眼皮，眼神疲惫但冷静，短黑发自然侧分，肤色偏冷白，有轻微黑眼圈和真实皮肤纹理。穿剪裁克制的深灰西装、白衬衫无领带、黑色皮鞋，左手自然下垂，右手轻扶袖口。画面右侧是他的黑色录音笔和旧合同夹设计图，录音笔约手掌长度，合同夹约 A4 尺寸，并用一只简化手部持握姿态体现比例关系；柔和侧光，85mm 人像镜头，中性构图，真实毛发和布料褶皱，无字幕、水印、文字标识。
```
