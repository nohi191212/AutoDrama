# 任务

根据角色设定和最终剧本，为每个主要角色生成稳定的人物形象图描述与生图 prompt。

# 输入

标题：{{title}}

最终剧本：
{{final_script}}

角色设定：
{{roles}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

人物形象图视图要求：{{role_appearance_view_requirement}}

# 要求

- `role_name` 必须填写角色设定中的 `name` 原文，例如“林浩”；不要填写角色 ID、字典键、`role_林浩` 这类内部标识。
- 每个主要角色至少输出一个 `base` 形象。
- `desc` 写给人读，包含年龄感、体型、五官、气质、稳定可复用的体貌特征，不写剧情剧透。
- `prompt` 直接用于人物形象图生成，必须写成完整生图提示词，不要写成设定摘要。每个 `prompt` 建议 180-320 个中文字符。
- `prompt` 必须包含：画面风格要求、人物形象图视图要求、年龄段、性别呈现、地域/时代气质、身高体型、头身比例、脸型、五官、眼神、发型发色、肤色/皮肤质感、常态表情、站姿或坐姿、手部状态、基础服装、鞋履、可复用配饰、材质纹理、干净背景、光线、镜头/构图。
- 对真人电影质感角色，要写真实摄影、真实皮肤纹理、自然毛发、布料褶皱、真实比例、电影感柔和布光；不要写三视图拼版。
- 对 2D/3D/CG 风格角色，要严格保留对应风格，不要混入真人摄影词；如“人物形象图视图要求”要求三视图，必须明确正面、侧面、背面并排，同一身高比例和同一服装细节。
- 角色识别点必须来自稳定体貌、气质、发型、服装剪裁、配饰和色彩关系；不要把某一件临时剧情道具、伤痕、血迹、雨水、表情崩溃当作 base 形象的唯一识别点。
- 如果角色在剧本中有职业或阶层身份，服装要体现身份但保持可复用，例如“剪裁克制的深灰商务西装”“洗旧黑色连帽外套”，不要只写“穿得很帅”“高级感”。
- `prompt` 必须明确无其他人物、无字幕、无水印、无文字标识、无多余肢体、不要夸张畸变。
- 不要把服装当作唯一识别特征。
- 不要混用与画面风格冲突的描述。
- 输出必须符合调用方提供的 JSON schema。
