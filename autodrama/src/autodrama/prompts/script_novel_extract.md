# 任务

压缩当前单集的完整小说正文，生成后续剧本、角色、场景、道具、分镜和视频生成使用的单集剧情依据。

# 输入

script_novel_full：
{{script_novel_full}}

# 要求

- 只依据 `script_novel_full` 进行压缩，不要引入正文外的信息。
- 保留本集的时间、人物、地点、关键事件、因果关系、情绪转折、关键道具/场景状态和结尾钩子。
- 删除重复动作、过细景色描写、可省略心理铺陈、不影响剧情推进的修辞和无关细节。
- 不要改名，不要新增原文没有的重要角色，不要提前剧透后续内容。
- 写成紧凑剧情摘要，不要写旁白，不要写分镜编号，不要写镜头语言。
- 输出 JSON 只能包含 `script_novel_extract` 一个字段。
- `script_novel_extract` 的值必须是压缩后的单集剧情摘要字符串。
- 输出必须符合调用方提供的 JSON schema。
