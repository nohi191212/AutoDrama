# 任务

从 `script_novel` 产生的全本完整小说中，为当前批次提取每集简略内容，形成后续详细剧本的剧情依据。

# 输入

标题：{{title}}

全本完整小说：
{{novel_full}}

已经提取的前序内容：
{{previous_extract}}

当前批次压缩提示：
{{extract_hints}}

项目约束（只用于保持风格、情绪和不能变的事实，不替代完整正文）：
{{project_context}}

当前批次必须输出的分集键名：{{batch_episode_keys}}

目标集数：{{episode_count}}

单集目标时长：{{episode_duration_seconds}} 秒

# 要求

- 输出 `novel_extract`，键名必须包含且只包含当前批次分集键名：{{batch_episode_keys}}。
- 每个键对应一集简略内容。
- 必须以“全本完整小说”中对应集的正文为主要依据；“当前批次压缩提示”只用于标定本集范围、压缩目标和必要取舍。
- 项目约束用于提醒故事核心、人物/场景锁定、情绪曲线和不能变的事实；如果它和全本完整小说有差异，以全本完整小说为准。
- 如果全本完整小说和压缩提示存在差异，以全本完整小说的实际剧情为准。
- 保留每集的时间、人物、地点、关键事件、因果关系、情绪转折和结尾钩子。
- 删除不重要的路人、重复动作、过细景色描写、可省略的心理铺陈和不影响剧情推进的修辞。
- 保留能影响后续角色、场景、道具、分镜和视频生成的稳定信息。
- 与已经提取的前序内容保持称谓、人物关系、道具状态、剧情连续性和文风一致。
- 不要改名，不要新增原文没有的重要角色，不要提前剧透后续批次的重大反转。
- 每集写成紧凑剧情摘要，不要写旁白，不要写分镜编号，不要写镜头语言。
- 输出必须符合调用方提供的 JSON schema。
