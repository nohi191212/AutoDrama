# 任务

从全本完整小说中提取所有需要作为可复用静态场景资产的地点/空间。

这个节点只做“场景提取”，不要生成生图 prompt。后续 `layout_design` 会按提取结果设计可直接生图的无人物场景 prompt。

# 输入

标题：{{title}}

原始故事：
{{raw_script}}

可用剧集键：{{episode_keys}}

完整小说正文（按集组织，每集可能包含“源章节：第X章-第Y章”等信息）：
{{novel_full}}

导演前期约束（用于识别关键空间、空间不变量和不能变的左右/前后/昼夜关系；不得替代完整小说正文）：
{{director_prep}}

角色设定：
{{roles}}

道具设定：
{{props}}

# 要求

- 只提取后续分镜、参考帧或视频生成需要反复引用的空间基准，包括主要地点、关键对峙空间、调查空间、追逐/动作空间、仪式/战斗空间、可复用室内外环境。
- 合并本质相同的地点，不要因为一次性镜头角度、临时人物动作或短暂道具摆放而拆成多个场景。
- 不要输出角色、道具、服装、车辆特写、纯天气、纯情绪氛围或没有明确空间锚点的概念。
- `name` 必须使用短名称，例如「雨夜办公室」「会议室」「破碎山门」「地铁站台」。
- `episode_keys` 必须列出该场景实际出现的全部剧集键，只能使用“可用剧集键”中的值，至少包含 1 个剧集。
- `source_chapters` 填写该场景出现的源章节范围或章节号，例如“第1章”“第3章-第5章”。如果正文只有分集没有源章节，则从该集开头的“源章节”信息推断；仍无法判断时填空数组。
- `brief` 用一句话说明该空间的剧情功能和复用价值，不要写成完整镜头或生图 prompt。
- `appearance_notes` 只记录正文已经明确给出的可见空间线索，例如时代地域、室内/室外、昼夜天气、结构关系、门窗墙地面、固定家具、标志性装置、材质、光线、破损、雾气、雨痕等；没有就填空数组。
- 不要输出 `prompt`、摄影机参数、完整生图描述或出图参数。
- 输出必须符合调用方提供的 JSON schema。
