# 任务

为当前单个角色生成完整角色设计。这个节点按角色递归运行，每次只设计一个角色，并参考已经设计完成的角色保持风格、关系和设定一致。

# 输入

标题：{{title}}

原始故事：
{{raw_script}}

当前角色提取结果：
{{role_extract_item}}

当前角色对应集/章节的完整小说正文（只包含该角色出现的相关集）：
{{role_novel_full}}

全角色提取结果：
{{all_role_extracts}}

已经完成的角色设计：
{{existing_role_designs}}

可用音色列表（共 {{available_voice_count}} 个；如果非空，必须从这里选择，不要编造）：
{{available_voices}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

人物形象图视图要求：{{role_appearance_view_requirement}}

# 总体要求

- 输出的 `roles` 数组只能包含当前角色这一项。
- `name` 必须和“当前角色提取结果”的 `name` 完全一致；不要填写角色 ID 或内部标识。
- 必须继承当前角色提取结果中的 `aliases`、`importance`、`episode_keys`、`source_chapters`，可以补充但不能删掉已知信息。
- 只依据当前角色对应集/章节的完整小说正文、原始故事、全角色提取结果和已有设计，不要引入与故事无关的新身份、新关系或新道具。
- 设计内容要包含：具体身份介绍、性格、人物关系、声音设计、外观设计、和角色强绑定的主要道具。
- 如果已有角色设计中已经确定了时代、地域、风格、职业体系、服饰体系、道具比例或人物关系，当前角色必须保持一致。
- 避免后期关键反转、结局、胜负结果或关键证据剧透；可以描述角色在故事前中期能稳定呈现的身份、气质和功能。
- 输出必须符合调用方提供的 JSON schema。

# 基本设定要求

- `intro` 写给人读，包含年龄感、身份、人物功能和稳定气质，不要写成长剧情梗概。
- `personality` 写 3-6 个性格/行为关键词，逗号分隔即可。
- `relationships` 只写和全角色提取结果或相关正文能支持的关系；`target_role_name` 必须填写对方角色原名；`relation` 写身份关系，`dynamic` 写互动张力，`evidence` 写简短依据。

# 声音设计要求

- `voices` 中每个角色至少生成一个 `normal` 音色；如果剧情需要，可以额外生成 `angry`、`sad`、`happy`、`tense`、`whisper` 或 `other`。
- 如果“可用音色列表”非空，每条声音设计必须从列表中选择同一个最适合该角色的音色，并逐字复制 `voice_name`、`voice_type`、`voice_resource_id`；`voice_resource_id` 对应列表里的 `resource_id`。
- 如果“可用音色列表”为空，不要编造 `voice_name`、`voice_type`、`voice_resource_id`，这些字段可以为空，但仍需写 `desc` 和 `sample_text`。
- `desc` 面向 TTS/音色模型，描述年龄感、性别感、音色、语速、情绪、咬字特点。
- `sample_text` 使用第一人称，格式为“身份自我介绍 + 前期内心独白”，约 60-120 个中文字符，不能涉及后期关键剧情、最终反转、关键证据、结局或胜负结果。

# 外观和道具设计要求

- `appearances` 至少输出一个 `base` 形象。
- `appearances[].role_name` 必须填写当前角色原名。
- `appearances[].desc` 写给人读，包含年龄感、体型、五官、气质、稳定可复用的体貌特征，不写剧情剧透。
- `appearances[].role_bound_props` 只列出和该角色强绑定、会影响角色识别或动作方式的主要物品，例如武器、法器、面具、戒指、包、常用工具；不要列全局剧情证物或只出现一次的普通背景物。
- 每个 `role_bound_props` 条目要写清可见特征、真实尺寸感、材质、状态、与角色整体身高或服装位置的比例关系、角色如何佩戴或使用。
- `appearances[].prompt` 直接用于生成角色设计图。设计图必须是同一张图：左侧为人物形象；右侧为其主要绑定物品设计图。右侧道具必须直接以左侧人物为比例参照，和左侧人物保持同一画布比例尺、同一地面基线或同一高度参照线，展示道具本体的真实大小关系、完整轮廓、结构细节和材质，不展示额外手掌、手指、手部持握姿态或其他身体部位。
- `appearances[].prompt` 建议 260-520 个中文字符，必须包含：画面风格要求、人物形象图视图要求、年龄段、性别呈现、地域/时代气质、身高体型、头身比例、脸型、五官、眼神、发型发色、肤色/皮肤质感、常态表情、站姿或坐姿、双臂自然状态、基础服装、鞋履、可复用配饰、材质纹理、干净背景、光线、镜头/构图。
- `appearances[].prompt` 必须明确：左侧是人物形象，右侧是主要物品设计图，右侧物品以正交或轻微透视方式单独陈列，并直接对照左侧人物身高、肩宽、腰线或脚边地面基线来体现真实比例；不要用独立刻度尺作为主要比例参照，不要用手掌、手指、手臂、持握姿态或真实身体部位作为比例参照；无其他人物、无字幕、无水印、无文字标识、无多余肢体、不要夸张畸变。
- `appearances[].prompt` 必须使用更温和的角色设定图表达。即使原文有战斗、死亡、尸化、伤口、血迹、恐怖变异等信息，也要改写成低风险视觉元素：病态苍白、疲惫眼神、异化纹理、服装破损、尘土、泥污、旧污渍、暗色裂纹、非写实纹样。不要写血液、血渍、开放性伤口、内脏、断肢、写实尸体或 gore 细节；衣服上的血迹统一替换为泥土、脏污或旧污渍。
- 右侧物品比例参照必须直接使用左侧人物：例如“道具与左侧人物保持同一比例尺”“道具底部与左侧人物脚边地面线对齐”“道具高度约为左侧人物身高的三分之一”。不要写“手掌长度”“手持比例”“简化手掌轮廓”“人物持握姿态”“放置一只真实手掌”等任何手部参照，也不要把刻度尺作为主要参照。
- 对真人电影质感角色，要写真实摄影、真实皮肤纹理、自然毛发、布料褶皱、真实比例、电影感柔和布光；不要写三视图拼版。
- 对 2D/3D/CG 风格角色，要严格保留对应风格，不要混入真人摄影词；如“人物形象图视图要求”要求三视图，必须明确正面、左面、背面并排，同一身高比例和同一服装细节。
- 角色识别点必须来自稳定体貌、气质、发型、服装剪裁、配饰和色彩关系；不要把某一件临时剧情道具、伤痕、血迹、雨水、表情崩溃当作 base 形象的唯一识别点。
- `intro_video_prompt` 用于后续以设计图为参考生成角色介绍视频。风格向 Seedance 官方示例靠拢：写成一段连续自然语言，引用参考素材时使用“参考图片1”或“图片1中的人物外观”，再用 `0-2 秒：...；2-5 秒：...；5-8 秒：...。` 这样的内嵌时间段描述动作和镜头，不要写成分镜数组、分条清单或方括号标签。
- `intro_video_prompt` 必须描述：人物站在洁净、亮度适中的虚空圆台上，圆台缓慢转动；人物做几个符合身份和性格的常见动作；如有绑定物品，要展示佩戴、握持或使用方式；视频整体符合人物常见场景气质，但背景仍保持干净抽象，不出现剧情剧透。
- `intro_video_prompt` 不要出现字幕、水印、文字标识或其他人物；如需声音，只写自然环境声或衣料、道具轻响，不要额外编写对白。
