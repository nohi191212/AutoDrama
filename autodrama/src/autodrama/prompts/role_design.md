# 要求

- 只列出剧情中必须出现的角色。
- 只能是一个人，不能是一群人。
- 每个角色需要包含姓名、给人看的简介、外貌特征（肤色、五官、身高、体重、体型、体貌特征，不是服装特征），性格关键词，这些介绍内容不要包含剧情情节，别名。
- 外貌特征要适配画面风格，能作为后续人物形象图的稳定参考；不要混用与画面风格冲突的视觉描述。
- 简介要包含年龄感、身份、性格、戏剧功能。
- 不要生成角色外形图 prompt，本节点只做基本设定。
- 输出必须符合调用方提供的 JSON schema。
