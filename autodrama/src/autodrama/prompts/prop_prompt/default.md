为下列每个道具资产写可直接用于图像生成的中文提示词：

道具：
{{props}}

统一美术：
{{prop_style_prompt}}

每个输入 assets 条目必须对应一个输出项，名称与引用关系保持不变。base 写一张干净中性背景上的单件道具参考图：主体完整、比例准确、材质和识别细节清楚，严格为手绘二维水墨国漫插画；无人物、手持、复杂环境、写实摄影、3D 产品渲染、工程图、正交多视图、拼图、可读文字、水印或 logo。variant 写基于其 reference base 的编辑提示，锁定同一二维水墨单件构图、结构、比例、材质和背景，只描述 `state_change`。

提示词只描述可见画面，不写尺寸、画幅、模型、路径、工作流或制作说明；不可辨读的纹样、笔迹和光痕可以保留，但不要要求生成可读文字。只输出符合给定 JSON Schema 的 JSON。
