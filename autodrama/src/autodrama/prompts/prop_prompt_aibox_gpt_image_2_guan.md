# 任务

根据去重后的结构化道具资产 `props` 和道具资产统一风格要求，输出后续道具图生成使用的纯文字提示词。

这个节点只写提示词文字，不生成图片，不输出尺寸比例，不输出画幅词，不输出模型名称。

# 输入

去重后的道具资产 props：
{{props}}

道具资产统一风格要求：
{{prop_style_prompt}}

# 输出字段

- `prop_asset_prompts`：数组。每个输入道具资产都必须输出一项。
- 每项包含：`prop_name`、`asset_name`、`prompt_type`、`reference_asset_name`、`prompt`。

# 输出匹配规则

- 每个输入 `props[].assets[]` 都必须输出一个提示词，不要新增输入中不存在的道具或资产。
- `prop_name` 必须与输入道具组 `name` 完全一致。
- `asset_name` 必须与输入资产 `name` 完全一致。
- `asset_role="base"` 的资产，`prompt_type` 必须是 `text_to_image`，`reference_asset_name` 为空或 null。
- `asset_role="variant"` 的资产，`prompt_type` 必须是 `image_edit`，`reference_asset_name` 必须与输入一致；通常是 `base`。

# 通用要求

- 提示词必须继承“道具资产统一风格要求”，但不要另行预设画面尺寸、画幅比例、横竖版、分辨率或固定模型名称。
- 不要出现 `16:9`、`9:16`、`1:1`、横向、竖向、portrait、landscape、asset sheet、三视图、设定板等尺寸或版式要求。
- 严格依据输入资产字段，不自由添加复杂机关结构、符号、铭文、品牌、文字内容或未给出的剧情功能。
- 所有道具默认无人物、无手持、无字幕、无水印、无 logo、无可读大段文字。
- 若道具本身是文件、屏幕、证件、标签或合同，可以出现版式、色块、签名位置、红圈或时间线形状，但不要依赖模型生成可读小字。
- 提示词要服务后续镜头参考，让视频生成能一眼识别道具、材质和状态。

# base 资产：文生图提示词

- 写成单个完整道具参考图，不是剧情截图、不是角色手持图、不是复杂场景分镜。
- 背景保持干净中性，主体完整清楚，允许简单接触面、自然阴影和少量材质反射，不要复杂环境。
- 写清主体轮廓、尺寸感、构件关系、材质、颜色、表面纹理、磨损/污渍/发光状态、识别细节、光线方向和背景干净程度。
- `visual_features` 是身份锁定重点，必须吸收进提示词。
- 不要把临时受损、战斗、染血、烧毁或激活状态写进 base，除非 base 本身就是输入中稳定常态。

# variant 资产：图片编辑提示词

- 写成基于参考图像的编辑提示词，开头明确“以 reference_asset_name 对应的基准道具图为参考”。
- 锁定不变：主体结构、比例、材质关系、颜色基底、构件位置、纹理密度、识别标志、接触面和背景简洁度。
- 只改变 `state_change` 中明确写出的可见变化，例如破损、污染、发光、变形、断裂、烧毁、激活后的能量纹路、血迹/锈迹/泥污变化、打开/关闭。
- 不重复 base 的完整外观，不把状态资产写成全新设计。
- 如果输入中 `state_change` 不足，保守描述状态，不编造额外结构。

# 输出要求

- 只输出 JSON，不要 Markdown，不要解释。
- 输出必须符合调用方提供的 JSON schema。
