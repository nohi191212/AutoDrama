# 任务

从全本完整小说中提取所有需要独立设计和独立生成图片的全局关键道具。

这个节点只做“道具提取”，不要生成生图 prompt。后续 `prop_design` 会按道具逐个递归设计。

# 输入

标题：{{title}}

原始故事：
{{raw_script}}

可用剧集键：{{episode_keys}}

完整小说正文（按集组织，每集可能包含“源章节：第X章-第Y章”等信息）：
{{novel_full}}

分钟片段（第一阶段按每 1 分钟画面单位拆分的剧情节奏，用于校验关键道具在镜头中的功能；不得替代完整小说正文）：
{{minute_segments}}

导演前期约束（用于识别必须保留的关键道具、证据状态和不能变的归属；不得替代完整小说正文）：
{{director_prep}}

角色设定：
{{roles}}

# 要求

- 只提取剧情推进、证据、冲突、反转、动作或角色决策中必须出现的全局关键道具。
- 不要输出泛泛的办公用品、背景陈设、普通家具或没有剧情功能的装饰物。
- `name` 必须使用小说中的稳定称呼；如果同一道具有多个关键可见状态，使用 `道具名_status` 命名，例如 `灵渊剑_normal`、`灵渊剑_damaged`。
- `status` 默认 `normal`。如剧情需要可使用 `damaged`、`transformed`、`activated` 等简短状态词。
- `episode_keys` 必须列出该道具或该状态实际出现的全部剧集键，只能使用“可用剧集键”中的值，至少包含 1 个剧集。
- `source_chapters` 填写该道具出现的源章节范围或章节号，例如“第1章”“第3章-第5章”。如果正文只有分集没有源章节，则从该集开头的“源章节”信息推断；仍无法判断时填空数组。
- `brief` 用一句话说明道具的剧情功能、归属或证据价值，不要写成分镜或剧情梗概。
- `appearance_notes` 只记录正文已经明确给出的可见线索，例如尺寸、材质、颜色、破损、纹路、发光状态、纸张色差、刻痕、污渍、封蜡、电子界面形态等；没有就填空数组。
- 不要输出 `prompt`、生图描述、镜头语言或出图参数。
- 输出必须符合调用方提供的 JSON schema。
