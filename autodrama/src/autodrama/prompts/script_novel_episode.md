# 任务

根据总大纲、分集大纲和已经写完的前序章节，扩写当前集为一章连续小说情节。

# 输入

标题：{{title}}

总集数：{{episode_count}}

单集目标时长：{{episode_duration_seconds}} 秒

当前集目标字数：{{target_char_count}} 字左右

必须使用的分集键名：{{episode_keys}}

当前集键名：{{current_episode_key}}

总大纲：
{{outline}}

完整分集大纲：
{{episode_outlines}}

当前集分集大纲：
{{current_episode_outline}}

已经写完的前序章节：
{{previous_chapters}}

# 要求

- 只写 `{{current_episode_key}}` 这一集，输出 JSON 中的 `episode_key` 必须等于 `{{current_episode_key}}`。
- `target_char_count` 必须等于 {{target_char_count}}。
- `novel_full` 写成连续小说正文，不要写成分镜表、提纲、条目列表或剧本格式。
- `novel_full` 的正文长度控制在 {{target_char_count}} 字左右，允许上下浮动约 15%；不要明显少写。
- 你的输入依据只有总大纲、完整分集大纲、当前集分集大纲和已经写完的前序章节；以前序章节为连续上下文，承接人物状态、道具位置、伤势、关系变化和悬念。
- 不要改写、复述或总结前序章节；只继续写当前集。
- 如果当前集分集大纲包含“源章节：第X章-第Y章。”，必须保留该标注作为正文开头，并且只扩写该源章节范围内的核心剧情。
- 如果原始分集规划来自章节章纲，继续保持“连续 2 章合并为 1 集”的覆盖关系；不得提前写入下一集章节的核心反转。
- 当前集必须有完整起承转合：承接上集、推动冲突、给出本集爽点或反转、结尾留下自然钩子。
- 可以写人物动作、心理、对白、环境、法术或道具细节，但所有视觉描述必须服务于后续分镜和视频生成。
- 场景、光线、材质、人物调度和关键视觉道具要与画面风格一致。
- 不要混用与画面风格冲突的视觉描述。
- 不要出现“旁白：”“镜头：”“画外音：”等剧本标签。
- 输出必须符合调用方提供的 JSON schema。
- 输出中，冒号""不能再有""，要替换成「」。

// 原始（会报错）
{"novel_full": "他说"你好"，然后就走了"}

// 你的方案（合法 JSON）
{"novel_full": "他说「你好」，然后就走了"}
