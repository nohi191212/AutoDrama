# 任务

为指定集生成电影级分镜 JSON。分镜会写入 slots 目录，不写入 state.json。

# 输入

标题：{{title}}

集键名：{{episode_key}}

本集最终剧本：
{{episode_script}}

前序分镜历史：
{{previous_storyboard_history}}

角色资产：
{{roles}}

道具资产：
{{props}}

场景资产：
{{layouts}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

# 输出目标

每个分镜都要像摄影指导、分镜师、动画导演和声音设计师可以直接执行的镜头说明。不要只写“大战”“气氛紧张”“镜头推进”这种抽象概括。你必须写出可被复现的画面事实：相机在哪里、镜头朝哪里、谁在画面哪个位置、光从哪里来、角色正在做什么、环境如何运动、声音如何进入身体、转场如何发生。

# 必填内容密度

每个 shot 的 `content` 至少要包含以下信息，不能少于 160 个中文字符：

- 场景与时间：地点、天气、昼夜、空间状态、地面/天空/背景物。
- 景别与机位：全景/中景/近景/特写，仰拍/俯拍/平视，机位放在哪里。
- 镜头与焦段：明确焦段或镜头类型，例如 16mm 广角、35mm、50mm、85mm。
- 构图：三分法、中心构图、前中后景、负空间、视觉张力线、主体边缘位置。
- 光源：主光来源、色温、遮挡、反射、光柱、轮廓光、阴影形状。
- 角色位置与表演：角色分别在画面哪个区域，姿态、视线、手部动作、呼吸、微表情。
- 服装/伤痕/道具状态：必须与已有角色、道具资产一致，可增加剧情造成的破损、雨水、血迹、能量状态。
- 环境与粒子：雨、雾、灰烬、碎石、水汽、能量脉冲等如何穿过画面。
- 声音设计：主声音、低频/环境声/雷声/呼吸/金属声等，必要时写体感。
- 相机运动：固定、推、拉、摇、移、环绕、震动；说明运动原因，不要只写“镜头运动”。
- 时长与转场：`duration_seconds` 写 4.0-15.0 秒范围内的镜头时长，优先使用整数秒以适配 Seedance 2.0；`transition` 写硬切、匹配剪辑、闪白、溶解等。

`scene_description` 写场景、天气、时间、空间关系。

`composition` 写景别、构图、人物/道具在画面中的位置、负空间和视觉张力。

`lighting` 写主光、辅光、轮廓光、反射、阴影和色温。

`sound_design` 写可执行的声音层次，尤其是非对白声音。

`camera_shooting_angle` 写机位、角度、镜头朝向和焦段。

`camera_movement` 写相机是否固定、如何运动、运动速度、抖动来源。

`ref_frame_prompt` 用于参考帧生图，必须是单帧画面描述，包含画面风格、场景、人物、道具、构图、光源、镜头焦段。不要写视频动作。

`video_prompt` 用于视频生成，必须包含 3-6 秒内发生的动作、角色微表情、环境粒子、相机运动、节奏和画面连续性。不要重复整段 `content`，但要保留关键运动。

# 镜头继承关系

每个 shot 必须选择 `start_frame_source`：

- 第一镜默认 `new_reference_frame`。
- 后续镜头如果与上一镜头在同一时空、同一动作连续、需要保持人物姿态/能量位置/镜头方向连续，则可选 `previous_shot_last_frame`。
- 如果发生时间跳跃、地点变化、视角大幅改变、闪回、插入镜头或需要重新建立空间，则选 `new_reference_frame`。
- `start_frame_inheritance_reason` 必须说明为什么继承或为什么不继承，20-80 个中文字符。
- 选择 `previous_shot_last_frame` 时，`content` 和 `video_prompt` 必须明确本镜头如何从上一镜头末尾状态开始，而不是重新摆拍。
- 选择 `previous_shot_last_frame` 会让视频生成阶段把上一镜头尾帧作为本镜头严格首帧使用；不要为了普通风格一致性滥用，只在动作、姿态、能量特效或空间方位必须无缝延续时使用。

# 电影镜头样例

下面是内容密度参考。不要原样复制，除非剧本确实需要同一场景；学习它的颗粒度、构图意识和声音设计。
示例中的 3.2 秒只作为节奏颗粒度参考；实际输出的 `duration_seconds` 仍需遵守上面的 4.0 秒以上约束。

```text
场景: 云天之上，破碎的仙山浮岛群，夜，暴雨倾盆。全景，极低角度仰拍，16 毫米广角镜头，相机置于一块破碎悬浮岩石的边缘，镜头朝上指向天空。暴雨斜向穿过画面，每一滴雨水都被头顶唯一光源照亮：一轮被黑云遮蔽、只剩一线银边的残月，月光从云缝中如剑般劈下，形成一道可见的垂直光柱，照亮两人的轮廓。两名角色位于画面顶部边缘，身形投影在惨白月光之上。反派渊帝位于右侧三分之一处，约四十岁，黑气缠身，残破铠甲胸口嵌暗紫色晶石，双臂低垂，指尖有黑焰如岩浆滴落，雨水接触黑焰后蒸发成白色蒸汽。正派云澜位于左侧三分之一处，白衣青年，眉心一点银色印记，长发散落，手握半透明灵渊剑，剑身内星河流淌；他半跪在浮石边缘，左手按住碎裂石面，指尖陷入石缝，胸口剧烈起伏，白袍多处撕裂，心口露出剑形银色疤痕，雨水沿下颌线滴落，混着嘴角血丝。声音以暴雨为主，混入来自渊帝体内的 40Hz 低频暗涌，像在胸腔里震动而非单纯听见，每三秒一次雷鸣。构图采用三分法，两人之间的负空间被月光光柱填充，月光如刀刃把画面劈成两半，在两人之间形成视觉张力线。相机固定，但浮石本身微弱晃动，让画面有呼吸般的颤动，不是手持，是大地本身在发抖。时长 3.2 秒，硬切。
```

# 基本约束

- `episode_key` 必须等于输入的集键名。
- 生成本集分镜时必须参考前序分镜历史，保持角色行动、场景位置、道具状态和镜头节奏连续。
- 不要重复前序集已经完成的关键动作，除非本集剧本明确要求回放、复现或呼应。
- 如需延续前序集的场景、角色或道具，必须使用已有 ID。
- 本集分镜只输出当前 `episode_key`，不要输出前序集分镜。
- 生成 3-9 个分镜，按 `index` 从 1 递增。
- 每个分镜必须引用已有 `layout_id`，如出现角色或道具，也必须引用已有 ID。
- `duration_seconds` 合计应接近本集目标时长；单个镜头通常 4.0-8.0 秒，动作复杂镜头可更长，但不要超过 15.0 秒。
- `bgm_id` 必须输出为 `null`，分镜和镜头动态资产生成阶段不要绑定 BGM。
- 不要引用不存在的角色、道具或场景。
- 输出必须符合调用方提供的 JSON schema。
