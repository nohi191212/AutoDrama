# 任务

根据分集小说全文提取全局关键道具，并为每个道具生成出现剧集、可用于状态索引的简介，以及可直接用于生图的 prompt。

# 输入

标题：{{title}}

可用剧集键：{{episode_keys}}

分集小说全文：
{{novel_full}}

角色设定：
{{roles}}

已经随人物设计的绑定物品：
{{role_bound_props}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

# 要求

- 只提取剧情推进、证据、冲突、反转或动作中必须出现的全局关键道具。
- 不要重复输出“已经随人物设计的绑定物品”；这些物品会跟随人物设计图生成。
- `episode_keys` 必须列出该道具或该状态实际出现的全部剧集键，只能使用“可用剧集键”中的值，至少包含 1 个剧集。
- `desc` 写道具的可见特征、尺寸感、材质、状态和戏剧功能。
- `prompt` 直接用于无人物道具图生成，必须写成完整生图提示词，不要写成道具摘要。每个 `prompt` 建议 120-260 个中文字符。
- `prompt` 必须包含：画面风格要求、道具主体、尺寸比例、形状轮廓、材质、颜色、磨损/破损/污渍/能量状态、关键识别细节、摆放环境、接触面材质、光线方向、镜头角度、焦段或景别、背景干净程度。
- 道具图必须无人物、无手持、无字幕、无水印、无文字标识；如道具本身是文件、屏幕、证件、标签或合同，可以出现版式、色块、红圈、签名位置、时间线形状，但不要依赖模型生成可读小字。
- 关键证据类道具要写清楚“为什么一眼能被认出是这个道具”：纸张颜色差异、折痕、封蜡、破损边缘、金属刻痕、数据线、红色批注、异常光点等。
- 动作类或奇幻类道具要写清楚静止状态下的形态，不要把 `prompt` 写成视频动作，例如不要写“正在飞出”“缓慢旋转”；可写“悬浮展示”“静置在石台上”“能量纹路微亮”这类单帧状态。
- `status` 默认 `normal`，如剧情需要可使用 `damaged`、`transformed` 等简短状态词。若使用非 normal 状态，`desc` 和 `prompt` 都要体现具体可见变化。
- 如果同一道具在剧情中存在多个关键可见状态，输出多条 props；`name` 使用 `道具名_status` 格式区分，例如 `灵渊剑_normal`、`灵渊剑_damaged`，并在 `status` 填写对应状态词。normal 版本应描述基础外观，其他状态在基础外观上说明变化。
- 不要生成泛泛的办公用品或无剧情功能的背景物。
- 输出必须符合调用方提供的 JSON schema。

# `prompt` 示例

证据道具示例：

```text
真人电影质感，无人物道具图，关键合同文件平放在深色木质办公桌上，A4 尺寸，左上角金属订书钉，纸张边缘轻微卷曲，第一页颜色比下方纸张略浅，右下角有红色批注圈和签名位置但不生成可读大段文字，旁边放一支黑色录音笔作为尺寸参照。冷白台灯从左上方照射，纸面纤维、折痕和轻微咖啡渍清晰，50mm 近景，背景干净虚化，无手、无人物、无字幕、水印。
```

奇幻/动作道具示例：

```text
爱死机风格写实CG，无人物道具图，半透明灵渊剑静置在破碎黑石台上，剑长约一米，细长剑身内部有星河状银蓝光纹，剑刃边缘有雨水凝结，剑柄为暗银金属缠黑色皮革，护手处有裂开的月牙纹。冷色侧逆光照出金属划痕和石台裂缝，35mm 中近景，背景为干净暗雾虚化，单帧展示，不出现挥砍动作、字幕、水印或文字标识。
```
