# 任务

为当前单个全局关键道具生成完整道具设计。这个节点按道具递归运行，每次只设计一个道具，并参考已经设计完成的道具保持风格、比例和状态命名一致。

{{prop_novel_full}}

# 总体要求

- 输出的 `props` 数组只能包含当前道具这一项。
- `name` 必须和“当前道具提取结果”的 `name` 完全一致；不要填写道具 ID 或内部标识。
- 必须继承当前道具提取结果中的 `status` 和 `episode_keys`，可以补充描述，但不能删掉已知出现集。
- 只依据当前道具对应集/章节的完整小说正文、原始故事、全道具提取结果、角色设定和已有设计，不要引入与故事无关的新功能、新归属或新状态。
- 导演前期约束只用于保持道具不变量和导演锁定边界；如果它与完整小说正文冲突，以完整小说正文为准。
- 如果已有道具设计中已经确定了时代、地域、职业体系、材质体系、证据样式、奇幻能量样式、比例尺度或状态命名，当前道具必须保持一致。
- 输出必须符合调用方提供的 JSON schema。

# 字段要求

- `desc` 写给人读，说明道具的可见特征、尺寸感、材质、状态、归属、剧情功能和识别点。
- `status` 默认 `normal`，如当前道具提取结果为非 normal，必须沿用该状态，并在 `desc` 和 `prompt` 中体现具体可见变化。
- `episode_keys` 必须列出该道具或该状态实际出现的全部剧集键，只能使用当前道具提取结果中的 episode key。
- `prompt` 直接用于无人物道具图生成，必须写成完整生图提示词，不要写成道具摘要。每个 `prompt` 建议 120-260 个中文字符。

# prompt 要求

`prompt` 必须包含：

- 画面风格要求；
- 道具主体；
- 尺寸比例；
- 形状轮廓；
- 材质、颜色和表面纹理；
- 磨损、破损、污渍、能量状态或其他当前状态细节；
- 一眼可识别该道具的关键细节；
- 摆放环境和接触面材质；
- 光线方向；
- 镜头角度、焦段或景别；
- 背景干净程度。

道具图必须无人物、无手持、无字幕、无水印、无文字标识。若道具本身是文件、屏幕、证件、标签或合同，可以出现版式、色块、红圈、签名位置、时间线形状，但不要依赖模型生成可读小字。

关键证据类道具要写清楚“为什么一眼能被认出是这个道具”：纸张颜色差异、折痕、封蜡、破损边缘、金属刻痕、数据线、红色批注、异常光点等。

动作类或奇幻类道具要写清楚静止状态下的形态，不要把 `prompt` 写成视频动作，例如不要写“正在飞出”“缓慢旋转”；可写“悬浮展示”“静置在石台上”“能量纹路微亮”这类单帧状态。

如果同一道具在剧情中存在多个关键可见状态，当前调用只设计“当前道具提取结果”对应的状态。normal 版本描述基础外观，其他状态在基础外观上说明变化。

# prompt 示例

证据道具示例：

```text
真人电影质感，无人物道具图，关键合同文件平放在深色木质办公桌上，A4 尺寸，左上角金属订书钉，纸张边缘轻微卷曲，第一页颜色比下方纸张略浅，右下角有红色批注圈和签名位置但不生成可读大段文字，旁边放一支黑色录音笔作为尺寸参照。冷白台灯从左上方照射，纸面纤维、折痕和轻微咖啡渍清晰，50mm 近景，背景干净虚化，无手、无人物、无字幕、水印。
```

奇幻/动作道具示例：

```text
爱死机风格写实CG，无人物道具图，半透明灵渊剑静置在破碎黑石台上，剑长约一米，细长剑身内部有星河状银蓝光纹，剑刃边缘有雨水凝结，剑柄为暗银金属缠黑色皮革，护手处有裂开的月牙纹。冷色侧逆光照出金属划痕和石台裂缝，35mm 中近景，背景为干净暗雾虚化，单帧展示，不出现挥砍动作、字幕、水印或文字标识。
```
