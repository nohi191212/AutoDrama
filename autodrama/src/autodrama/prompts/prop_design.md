# 任务

根据最终剧本提取关键道具，并为每个道具生成可用于生图的描述和 prompt。

# 输入

标题：{{title}}

最终剧本：
{{final_script}}

角色设定：
{{roles}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

# 要求

- 只提取剧情推进、证据、冲突、反转或动作中必须出现的关键道具。
- `desc` 写道具的可见特征、尺寸感、材质、状态和戏剧功能。
- `prompt` 直接用于无人物道具图生成，要包含画面风格、道具主体、材质细节、干净背景或合理摆放环境。
- `status` 默认 `normal`，如剧情需要可使用 `damaged`、`transformed` 等简短状态词。
- 不要生成泛泛的办公用品或无剧情功能的背景物。
- 输出必须符合调用方提供的 JSON schema。
