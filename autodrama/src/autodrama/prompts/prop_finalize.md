# 任务

检查已有道具介绍 `generated_prop_intro`，合并重复道具并统一命名。

这个节点只做去重、合并和命名规范化，不读取剧本文本，不新增剧情里未给出的道具，不写生图 prompt。

# 输入

已有道具介绍 generated_prop_intro：
{{generated_prop_intro}}

# 输出字段

- `generated_prop_intro`：去重后的完整道具介绍对象。
- `merge_notes`：简短说明合并、重命名、保留状态道具或删除重复项的原因。

# 要求

- 输出必须是完整的去重后 `generated_prop_intro`，不是差异补丁。
- 如果多个键本质上是同一个道具，保留一个短名称，并把可复用外观、功能、归属或证据信息合并进一句话介绍。
- 不要因为同一道具的一次性摆放位置、临时手持者、镜头角度、称呼差异或轻微描述差异拆成多个道具。
- 如果 `道具名_状态` 确实代表同一道具的不同关键可见状态，并且需要独立参考图，则保留状态道具。
- 状态道具的值必须只写相对原道具的变化；如果状态值重复了原道具完整介绍，要改成变化描述。
- 如果状态道具没有对应原道具，但能从名称判断原道具，应保留状态键并在变化描述中避免编造原道具细节。
- 如果某个条目明显不是道具，比如人物、场景、服装、普通背景家具、纯天气、纯情绪或技术字段，应删除。
- 不要输出 episode_keys、source_chapters、prompt、asset_path、URL、ID、模型名称或图片参数。
- 输出必须符合调用方提供的 JSON schema。
