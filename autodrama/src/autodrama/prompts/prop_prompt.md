# 任务

根据去重后的道具一句话介绍和导演预生成的 visual_tone，输出后续道具图生成使用的纯文字提示词。

这个节点只写提示词文字，不生成图片，不输出尺寸比例，不输出画幅词，不输出模型名称。

# 输入

去重后的道具介绍 generated_prop_intro：
{{generated_prop_intro}}

导演 visual_tone：
{{visual_tone}}

# 输出字段

- `prop_prompts`：对象，键必须与输入 `generated_prop_intro` 的道具名完全一致，值为对应道具的纯文字生图提示词。

# 要求

- 每个输入道具都必须输出一个提示词，不要新增输入中不存在的道具名。
- 提示词必须继承 `visual_tone`，但不要另行预设画面尺寸、画幅比例、横竖版、分辨率或固定模型名称。
- 不要出现 `16:9`、`9:16`、`1:1`、横向、竖向、portrait、landscape、asset sheet、三视图、设定板等尺寸或版式要求。
- 原道具指不带 `_状态` 后缀的道具。原道具提示词要写成专业、可复用的无人物道具参考图提示词，包含主体、尺寸感、形状轮廓、材质、颜色、表面纹理、磨损/污渍/能量状态、识别细节、摆放环境、接触面、光线方向和背景干净程度。
- 状态道具指形如 `道具名_状态` 的道具。状态道具提示词要写成基于参考图像的变化提示词：明确“保持原道具主体结构、比例、材质关系和识别细节不变”，只描述相比原道具要改变的状态，例如破损、污染、发光、变形、断裂、烧毁、激活后的能量纹路、血迹/锈迹/泥污变化。
- 状态道具提示词不要重复原道具完整外观；它会在生图阶段尽量使用原道具图作为参考图。
- 所有道具默认无人物、无手持、无字幕、无水印、无 logo、无可读大段文字。若道具本身是文件、屏幕、证件、标签或合同，可以出现版式、色块、签名位置、红圈或时间线形状，但不要依赖模型生成可读小字。
- 提示词要服务后续镜头参考，让视频生成能一眼识别道具、材质和状态。
- 输出必须符合调用方提供的 JSON schema。
