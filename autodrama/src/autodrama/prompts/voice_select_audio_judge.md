# 任务

你将听 top 5 候选音色的一段或多段样例，并为当前角色选择一个最适合长期复用的官方音色。

# 输入

角色设定：
{{role_design}}

top 5 候选音色画像：
{{candidate_profiles}}

音频样例说明：
{{sample_refs}}

# 要求

- 你不是判断台词内容，而是判断音色是否适合角色。
- 优先判断年龄感、性别呈现、身份匹配、性格匹配、情绪表现稳定性、短剧对白自然度。
- 同一个角色后续所有对白会复用同一音色，宁可选择稳定自然，也不要选择只在某一情绪里夸张的音色。
- 警惕过强广告腔、客服腔、播音腔、动漫腔。
- 如果官方描述和实际听感冲突，以实际听感为准。
- 输出必须符合调用方提供的 JSON schema。
