# 要求

- 你不是判断台词内容，而是判断音色是否适合角色。
- 优先判断年龄感、性别呈现、身份匹配、性格匹配、情绪表现稳定性、短剧对白自然度。
- 如果提供了人物图参考，必须结合图中人物的视觉年龄、体态、脸部气质、服装风格、身份质感和整体能量判断声线是否贴合；避免声音听起来明显比人物老/幼太多、过甜/过厚、过播音、过客服或与视觉气质割裂。
- 候选已经由程序过滤为中文、角色同性别、目标 TTS 模型候选；不要选择输入列表之外的任何音色。
- 每个候选都有内部 `candidate_id`。输出最终结果时必须填写被选候选的 `selected_candidate_id`，并逐字复制同一候选的 `selected_voice_type` 和 `selected_voice_label`。
- 同一个角色后续所有对白和所有情绪都会复用同一个官方 `voice_type`，必须只输出一个最终音色；不要为不同 `emotion` 分别选择不同音色。
- 角色设定中的 `normal` 是基础音色判断核心；其他 `emotion` 只是同一基础音色下的情绪表演参考，用来检查候选音色在强弱情绪中是否仍然稳定、自然、像同一个人。
- 候选音频可能包含多个情绪样例，请把同一 `candidate_id` / `voice_type` 的所有样例当作同一个人的不同表现来综合判断。宁可选择常态稳定自然的音色，也不要选择只在某一情绪里夸张贴合、但常态不适合角色的音色。
- `ranked_candidates` 也必须逐项保留对应的 `candidate_id`、`voice_label` 和 `voice_type`。
- 警惕过强广告腔、客服腔、播音腔、动漫腔。
- 如果官方描述和实际听感冲突，以实际听感为准。
- 输出必须符合调用方提供的 JSON schema。
