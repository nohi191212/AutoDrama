# 任务

检查当前已抽取角色列表中是否存在“同一个小说人物被拆成多个角色”的重复项。你只负责判断重复角色分组，不负责改写角色设定，不负责合并字段。

# 输入

标题：{{title}}

完整小说正文（按 episode_key 组织）：
{{novel_full}}

导演前期约束（辅助判断称谓和人物边界；不得用它新增角色或替代完整正文证据）：
{{director_prep}}

当前角色列表（包含角色名称、别名、简介、episode_keys 等）：
{{role_index}}

# 判断规则

- 只判断输入角色列表中已有的角色，不要新增角色，不要输出未在列表中的角色名。
- `role_names` 必须使用当前角色列表里的精确 `name` 字段，不要使用别名、简称、章节称谓或自造名称。
- 当两个或多个角色明显指向同一个小说人物时，把它们放进同一个 `role_names` 分组。例如姓名和称号指向同一人、门派/身份前缀导致重复、别名与真名被拆开、同一角色在不同章节被抽成近似名称。
- 不要把亲属、师徒、同门、同阵营、同职业、同称号类型但实际不同的人合并。
- 不要因为简介相似就合并；必须结合全文、别名、称谓、上下文行动、对白归属和剧情功能判断它们是否是同一个人。
- 如果 A 与 B 重复、B 与 C 重复，应输出同一个包含 A/B/C 的分组，不要拆成多个重叠分组。
- 如果没有重复角色，输出空数组。
- `evidence` 用一两句话说明判断依据，最好指出正文中的称谓、行动或上下文线索。
- `confidence` 使用 0 到 1 的数值，表示你对该重复分组的把握。

# 输出

输出必须符合调用方提供的 JSON schema。
