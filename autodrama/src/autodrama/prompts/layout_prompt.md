# 任务

根据去重后的场景一句话介绍和导演预生成的 visual_tone，输出后续场景图生成使用的纯文字提示词。

这个节点只写提示词文字，不生成图片，不输出尺寸比例，不输出画幅词，不输出模型名称。

# 输入

去重后的场景介绍 generated_layout_intro：
{{generated_layout_intro}}

导演 visual_tone：
{{visual_tone}}

# 输出字段

- `layout_prompts`：对象，键必须与输入 `generated_layout_intro` 的场景名完全一致，值为对应场景的纯文字生图提示词。

# 要求

- 每个输入场景都必须输出一个提示词，不要新增输入中不存在的场景名。
- 提示词必须继承 `visual_tone`，但不要另行预设画面尺寸、画幅比例、横竖版、分辨率或固定画风词。
- 不要出现 `16:9`、`9:16`、`1:1`、横向、竖向、portrait、landscape 等尺寸、比例或画幅要求。
- 原场景指不带 `_状态` 后缀的场景。原场景提示词要写成专业、可复用的空场景参考图提示词，包含空间类型、入口/墙面/地面/天花或天空边界、固定结构、主要陈设、可走动区域、镜头可取景区域、材质、光线和氛围。
- 状态场景指形如 `场景名_状态` 的场景。状态场景提示词要写成基于参考图像的变化提示词：明确“保持原场景空间结构、固定陈设、材质关系和镜头锚点不变”，只描述相比原场景要改变的状态，例如昼夜、天气、灯光、破损、污染、烟尘、火光、仪式痕迹或战斗后变化。
- 状态场景提示词不要重复原场景完整空间介绍；它会在生图阶段尽量使用原场景图作为参考图。
- 所有场景默认是无人空场景。不要出现人物、背影、手、剪影、人群、照片里的真人、海报人物、字幕、水印、logo、可读门牌或屏幕文字；除非场景介绍明确需要，也不要生成可读文字。
- 提示词要服务后续镜头参考，让视频生成能判断角色可以站在哪里、道具可以放在哪些表面、镜头可以从哪些方向取景。
- 输出必须符合调用方提供的 JSON schema。
