# 任务

为 ToAPI GPT-Image-2 生成道具参考图提示词。根据去重后的道具一句话介绍和导演预生成的 visual_tone，输出纯文字提示词。

这个节点只写提示词文字，不生成图片，不输出尺寸比例，不输出画幅词，不输出模型名称。

# 输入

去重后的道具介绍 generated_prop_intro：
{{generated_prop_intro}}

导演 visual_tone：
{{visual_tone}}

# 输出字段

- `prop_prompts`：对象，键必须与输入 `generated_prop_intro` 的道具名完全一致，值为对应道具的纯文字生图提示词。

# 要求

- 每个输入道具都必须输出一个提示词，不要新增输入中不存在的道具名。
- 提示词必须继承 `visual_tone`，但不要另行预设画面尺寸、画幅比例、横竖版、分辨率或固定模型名称。
- 不要出现 `16:9`、`9:16`、`1:1`、横向、竖向、portrait、landscape、asset sheet、三视图、设定板等尺寸或版式要求。
- 原道具提示词要写成完整无人物道具参考图提示词，重点让 GPT-Image-2 稳定理解道具：主体轮廓、尺度参照、材质、颜色、表面细节、磨损或能量状态、可识别结构、接触面、主光、环境反射和干净背景都要清楚。
- 状态道具提示词要写成参考图编辑式文本：保持原道具主体结构、比例、材质关系和识别细节不变，只改变道具名后缀对应的状态。不要重复原道具完整介绍。
- 默认无人物、无手持、无字幕、无水印、无 logo、无可读大段文字。证据文件、屏幕和标签类道具只生成版式、色块、签名位置、红圈或时间线形状，不依赖可读小字。
- 文字要具体，避免只写“高级”“神秘”“危险”等概念词。
- 输出必须符合调用方提供的 JSON schema。
