# 生成原则

- `roleboard_prompt` 是最终要直接传给 GPT-Image-2 High 的图像提示词，不是分析稿、不是剧情复述、不是中间设计说明。
- 人物介绍是身份锁定的唯一核心来源。优先锁定稳定 base 形象：角色名、年龄感、性别、族群/地域气质、身高体型、脸型五官、发型、肤色状态、服装结构、鞋履/赤脚、手部、姿势语言、核心情绪和关键视觉标志。
- `visual_tone` 只用于继承项目的摄影、美术、材质、光线、表演质感和整体审美气质；不要把剧情环境、场景、事件、氛围道具带进背景。角色板背景始终保持纯白色、柔和米白色或干净浅灰色。
- High 模板可以写得更细：面部比例、发丝轮廓、服装旧化/材质、袖口/领口/鞋履或赤脚、手指、肩背姿态和情绪细节要更可视化；但不要增加人物介绍之外的长期身份设定。
- 不要在 `roleboard_prompt` 里提到 GPT-Image-2、provider、模型名、路径、文件名、节点名或项目 ID。

# roleboard_prompt 写法

请让 `roleboard_prompt` 接近下列规则内化的成品提示词形态，使用中文，段落清楚，可以包含换行。不要额外添加“某某｜角色身份板提示词”标题，建议直接从 `[主体]：...` 开始。

`roleboard_prompt` 必须包含以下内容：

- `[主体]` 段：用一句高密度视觉描述写清角色的稳定形象，类似“[主体]：角色名，年龄感/身份气质/体型/脸型/五官/发型/服装/鞋履/姿势语言/情绪范围/视觉标志。使用纯白色 / 柔和的米白色背景。”
- 明确禁止项：无环境、无道具、无标志、无水印。
- 设计方向：不要创建标准角色参考表；创建电影般的身份板，像高端动画工作室的角色研究与艺术书布局的结合。
- 布局要求：不对称、优雅、视觉上令人难忘；使用大片留白、多样化的图像比例和有意的不平衡；避免网格、蓝图设计、目录布局和重复的转场展示。
- 重要布局规则：不要重叠任何角色图像；每个视角必须有清晰分离和呼吸空间；身体、肖像、轮廓和细节研究保持视觉区分；无裁剪面部、无隐藏肢体、无堆叠人物、无合并姿势。
- 主要构图：一个大型英雄全身视角略微偏离中心作为视觉锚点；周围以干净间距排列较小辅助研究，包括中性全身视角、背面视角、侧面视角、坐姿、倾斜姿势、蹲姿、俯视身体角度、仰视身体角度、富有表现力的肖像研究。
- 独立研究感：每个视角都像独立、干净的角色研究，不像剧情场景帧。
- 身份锁定：所有视角严格保持相同面部、相同面部比例、相同发型、相同服装、相同身体比例、相同姿势语言和相同视觉个性。
- 有用参考细节：列出最利于未来图像和视频生成的脸部轮廓、发型轮廓、服装轮廓、身体形状、手部/鞋履/赤脚、肩背姿态、情绪范围和视觉标志。
- 艺术性部分：包含一个小轮廓研究区域，带 2-3 个简化黑色角色轮廓；包含一个小表情研究区域，展示 4-5 个细微情感变化；包含一个小细节研究区域，展示面部、头发、服装材质、袖口/领口/鞋履或赤脚等关键视觉特征。
- 文本设计：添加一个时尚的角色 ID 块，保持简约、大胆、艺术导向；ID 块仅使用“名称、角色、核心情绪、视觉标志”四类信息。仅在有帮助的地方使用小型手写风格标签；允许细微编辑箭头和标注标记，但保持简约和优雅。
- 风格：简约、电影感、高端、艺术书般、干净、富有表现力、适用于制作。最终图像应帮助 AI 模型理解角色的面部、轮廓、服装、姿势和情感范围。

# 输出要求

- 只输出 JSON。
- JSON 只能包含以下字段：`roleboard_prompt`、`roleboard_negative_prompt`、`voice_profile_prompt`、`design_notes`。
- `roleboard_prompt` 必须是一条可直接传给 GPT-Image-2 High 的完整图像 prompt。
- `roleboard_negative_prompt` 写明确避免项，至少覆盖：标准网格角色表、剧情海报、分镜、环境背景、无关道具、额外人物、变脸、换衣服、年龄漂移、发型漂移、体型漂移、肢体缺失、重叠人物、裁切面部、隐藏肢体、字幕、水印、logo、乱码、错误角色名、真实明星脸、真实身份证照。
- `voice_profile_prompt` 如果人物介绍显示角色有台词，写 1 段稳定声音画像；如果无台词，可以为空字符串。
- `design_notes` 简短说明你如何使用 visual_tone、人物介绍中哪些信息不足或需要后续人工确认；可以为空字符串。
