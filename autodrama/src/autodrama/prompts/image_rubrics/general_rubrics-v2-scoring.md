# general_rubrics-v2 · 评分细则

## 统一评分协议

- 只按成图中可观察到的证据评分，不因为提示词“写对了”而给分。
- 每个维度先匹配 `0 / 2 / 4 / 6 / 8 / 10` 锚点；介于相邻锚点时才使用奇数分。`10` 只给原始分辨率下近乎无可挑剔的结果，`8` 已代表专业强结果，不能把“看起来不错”默认记为 8 或 9。
- `6` 是最低可接受线。生产审计只计算适用维度和类别的纯加权分，任何 gate、严重度或单项低分都不得封顶、截断或替换总分；critical 可独立阻止交付，但不改变分数。离线模板锦标赛如需非线性封顶，只由 `evaluation_protocol-v3.json` 在 rubric 之外执行。
- 对故事明确要求的细节，“看不清、无法确认、可能是对的”必须按可见证据充分度给低分，不能按无罪推定给高分；生产审计不预设固定最高分。
- 仅当场景确实不涉及该维度时使用 `N/A`；构图把证据裁掉不算 N/A。
- 同一缺陷可以影响多个维度，但必须是不同后果。例如“双手误持单手剑”分别影响指定侧、额外接触和道具持法；报告必须写明各维度具体扣分原因，并用归一化 `x1,y1,x2,y2` 标出缺陷区域。
- 每项适用维度必须输出可观察证据和具体缺陷；低于 10 分却没有可命名缺陷的评分无效。major/critical 缺陷没有区域坐标的评分无效。
- 生产审计使用当前节点配置的评审模型和 `production_protocol-v1.json`；离线双评审模板锦标赛才按 `evaluation_protocol-v3.json` 执行独立评分、保守聚合与分歧复核。
- 评分顺序固定：身份库存 → 动作/左右/接触 → 空间/相机 → 构图/镜头 → 解剖/物理 → 光照 → 条件维度 → 证据存活。

## 逐维锚点

### 1. 剧情与身份忠实度 `story_identity` · gate

- 10：姓名/角色、年龄阶段、服装身份、情绪转折和事件瞬间全部准确，无新增剧情。
- 8：核心身份与事件准确，仅有不改变含义的年龄观感或次要服饰偏差。
- 6：角色仍可辨、主事件正确，但一个重要状态偏弱或含糊。
- 4：一个核心身份/年龄/事件结果明显错误，或新增内容改变叙事。
- 2：多个核心事实错误，只剩题材相似。
- 0：人物或事件完全不是源场景。
- 硬失败：主角身份错误、关键事件反转、必需状态缺失到无法识别。

### 2. 人物与物件库存 `inventory` · gate

- 10：人物、动物和关键物件数量逐项完全一致，无重复或额外对象。
- 8：所有关键库存正确，仅有不易误认的微小背景杂物。
- 6：核心人数正确，但一个次要必需物件弱化或疑似重复。
- 4：多/少一个人物，或关键道具缺失/重复。
- 2：人数和物件多处失控。
- 0：库存与要求无关。
- 硬失败：任何额外人物、重复主角、缺失剧情必需对象。

### 3. 单一动作时相 `action_phase` · gate

- 10：蓄力/初触/峰值承重/释放/早期恢复只有一个时相，身体、衣物、道具与环境反馈全部同步。
- 8：主时相明确，仅一个次要边缘反馈略早或略晚。
- 6：动作能读懂，但接触与身体姿态存在轻微时相混合。
- 4：同时出现“尚未触碰”和“已经产生后果”等明显矛盾。
- 2：动作是静态摆拍或多个时间状态拼合。
- 0：要求的动作没有发生。
- 硬失败：核心动词无法从单帧验证，或前因/结果互相矛盾。

### 4. 解剖左右与屏幕映射 `laterality` · gate

- 10：每个指定手、脚、眼、眉、方向及其 screen side 全部一致且清楚。
- 8：侧别正确，只有一个非关键部位因透视略难判。
- 6：核心侧别大体正确，但一处证据弱或身体扭转造成歧义。
- 4：一个剧情关键侧别被交换，或指定单侧特征出现在错误侧。
- 2：多处左右颠倒或同一人物内部自相矛盾。
- 0：无法建立人物侧别。
- 硬失败：指定动作肢体或面部标记明确落在错误解剖侧。

### 5. 接触拓扑与承重 `contact_topology` · gate

- 10：所有必需接触点、分离间隙、脚底承重、武器相交和受力链精确可信，无穿模。
- 8：核心接触正确，次要接触影或压力形变略弱。
- 6：接触关系可读，但边缘有轻微融合、悬浮或承重不稳。
- 4：一个核心接触点缺失、穿透或接错对象。
- 2：多处悬浮、融合或受力路径断裂。
- 0：动作拓扑完全错误。
- 硬失败：必需接触不存在、禁触对象相接、主体无可信支撑。

### 6. 连续空间与统一透视 `continuous_space` · gate

- 10：地面、建筑、人物与远景构成一个连续可行走空间，同一透视系统和尺度衰减。
- 8：整体连续，仅有轻微背景尺度或结构连接偏差。
- 6：主空间成立，但一个远景连接或消失关系含糊。
- 4：地面断裂、建筑不可能连接或出现两套透视。
- 2：人物像贴在不同平面或空间拼贴。
- 0：无法解释为单一场所。
- 硬失败：关键人物或物体无法处于同一个连续物理空间。

### 7. 相机锚点与方向 `camera_anchor` · gate

- 10：视点高度、世界位置、朝向和动作轴均与约束吻合，可从画面反推。
- 8：主要方向正确，轻微俯仰或横向偏移不影响关系。
- 6：大致机位正确，但一项方向证据不充分。
- 4：相机位于错误区域或越过既定动作/对话轴。
- 2：视点与世界地图互相矛盾。
- 0：无法建立相机位置。
- 硬失败：错误机位导致左右、进入/离开、前后关系反转。

### 8. 主体视觉层级 `protagonist_hierarchy`

- 10：第一眼主体明确，同时保留环境和关系信息，无强行居中。
- 8：主体清楚，仅有次要元素稍抢注意力。
- 6：主体可找出，但层级较平或视觉竞争明显。
- 4：配角、特效或背景成为实际主角。
- 2：没有稳定视觉入口。
- 0：主体缺失或不可见。

### 9. 多主体深度层级 `depth_hierarchy` · gate

- 10：每个主体的前中后景、表观尺度、遮挡和轮廓分离全部准确。
- 8：深度关系正确，只有轻微轮廓黏连。
- 6：谁前谁后可辨，但尺度或遮挡略平。
- 4：配角跑到错误深度面或遮住主动作。
- 2：多人物像同一平面贴纸或互相融合。
- 0：人物关系无法识别。
- 硬失败：剧情规定的后方人物/威胁进入错误前景，或关键人物重叠不可辨。

### 10. 视频帧感与去海报化 `episode_frame` · gate

- 10：未完成动作、非对称边距、动机裁切/遮挡、画外关注和延续空间同时成立，明显像剧集截帧。
- 8：至少四项成立，仅有轻微“关键视觉”摆拍感。
- 6：具备部分截帧证据，但构图仍偏完整、居中或英雄化。
- 4：明显对称站姿、加冕光、标题留白或正面展示。
- 2：宣传海报/角色卡/商品图语法占主导。
- 0：非单一视频帧，如拼贴、分镜或海报版式。
- 硬失败：主构图本质是宣传海报而非叙事瞬间。

### 11. 剧情证据型视觉钩子 `visual_hook`

- 10：一秒内读到唯一钩子，且钩子直接证明动作、边界、目光、尺度或光照事件。
- 8：钩子明确并有剧情作用，略有次级竞争。
- 6：钩子存在但较普通，需搜索才能理解。
- 4：钩子是装饰光效或与剧情无关的奇观。
- 2：多个钩子互相争夺。
- 0：无可辨视觉入口。

### 12. 镜头透视与景深 `lens_dof`

- 10：焦距观感、近远尺度、边缘变形和焦面共同服务证据，无矛盾镜头语言。
- 8：镜头合理，仅有轻微背景过虚或边缘拉伸。
- 6：主体清楚，但景深/透视有模板化感。
- 4：关键手、接触或人物被不合理虚化/畸变。
- 2：焦面与叙事目标相反，或透视严重失真。
- 0：镜头关系不可用。

### 13. 动势惯性与物理反馈 `physics_momentum`（旧版汇总项，2.4 起不再单独计分）

- 10：重心、惯性、主力方向、反作用、衣发和环境反馈完全同向且有重量。
- 8：主体力学可信，一个次要反馈略弱。
- 6：动作可读但偏轻、偏摆拍或环境反馈不足。
- 4：重心与力方向冲突，反作用不合理。
- 2：身体和环境各自朝不同时间/方向运动。
- 0：违反基本重力或力学。

### 14. 五官肢体手脚可信度 `anatomy` · gate

- 10：脸、关节、手指、脚趾/鞋、肢体长度和姿势完整自然。
- 8：整体可信，只有极小手指/关节造型瑕疵。
- 6：没有多肢或融合，但手脚/表情略僵硬。
- 4：一处明显多指、缺指、关节折断或脸部融合。
- 2：多处严重解剖错误。
- 0：主体身体不可用。
- 硬失败：额外肢体、融合手、断裂关节、不可修复面部畸变。

### 15. 光源方向与阴影一致性 `light_direction` · gate

- 10：每个主要光源都能解释受光面、投影、接触影、反射和空气可见性。
- 8：主光完全一致，次要反弹略泛。
- 6：总体方向合理，但一个阴影或轮廓光缺乏来源。
- 4：脸、物体和地面受光方向互相冲突。
- 2：多处无来源高光/阴影。
- 0：光照不具物理方向。
- 硬失败：关键光源与主体明暗面明确相反。

### 16. 曝光、反弹与局部溢光逻辑 `exposure_spill`

- 10：高光滚降、暗部层次、反弹色和发光衰减自然，材质均可读。
- 8：曝光健康，仅局部略亮或暗。
- 6：信息仍在，但高光/暗部一处压缩明显。
- 4：发光大面积污染、暗部死黑或高光剪切遮掉证据。
- 2：HDR/辉光主导画面。
- 0：曝光使场景不可读。

### 17. 雾粒子水花与特效可读性 `effects_restraint`

- 10：效果数量、方向、尺度和遮挡都服务空间或动作，完全不替代几何。
- 8：效果克制，一小块略显装饰。
- 6：效果偏多但关键证据仍可辨。
- 4：粒子/雨/火花遮挡手脸接触或制造假结构。
- 2：特效成为主要内容。
- 0：画面因特效不可审计。

### 18. 服装状态与缝线连续性 `wardrobe_integrity` · gate

- 10：服装身份、完整/破损状态、层次、缝线和衣片连接全部符合叙事。
- 8：状态正确，仅有轻微边缘磨损或层次简化。
- 6：整体可穿且身份正确，但局部毛边/褶皱接近不合理。
- 4：把完整旧衣画成破布、衣片穿插或关键结构缺失。
- 2：服装融合、随机破洞或身份错乱。
- 0：服装不可解释。
- 硬失败：明确 intact 的服装被严重撕裂，或衣服结构穿模到身体。

### 19. 道具状态与机械构型 `prop_state_mechanism` · gate

- 10：封口/开启、入鞘/出鞘、绳结、机关、刀剑结构和工作状态完全正确。
- 8：功能与状态正确，仅有非关键结构简化。
- 6：道具可识别且大体能工作，但一个连接弱。
- 4：状态错误，如整剑出鞘代替半出鞘，或机械链断开。
- 2：道具结构不可能工作或自相矛盾。
- 0：道具缺失/变成其他物体。
- 硬失败：剧情依赖的道具状态或机构错误。

### 20. 持有与接触排他性 `contact_exclusivity` · gate

- 10：每只活动手/脚只接触声明对象；所有空闲、禁止接触的肢体都有清楚间隙。
- 8：排他关系正确，某个空闲肢体间隙略小但仍可辨。
- 6：主要归属正确，一个非关键接触存在歧义。
- 4：本应空闲的手加入持握，或一个手同时不可能地接触两物。
- 2：多肢体归属混乱。
- 0：无法判断谁持有什么。
- 硬失败：明确 one-hand-only 被双手持有；禁止触碰者接触关键物。

### 21. 边界两侧与区域占位 `boundary_zone_occupancy` · gate

- 10：人物/脚/物体严格处于指定分区，边界连续可见并位于要求的接触点之间。
- 8：分区正确，边界局部被轻微遮挡。
- 6：区域关系大体正确，但一个接触点靠近边界难判。
- 4：关键人物或双脚落在同一错误侧。
- 2：分区地图与画面相反。
- 0：边界不存在。
- 硬失败：跨越场景中边界不在两接触点之间，或人物站到墙/禁区上。

### 22. 眼神线、关注目标与对话轴 `eyeline_axis` · gate

- 10：所有眼神准确汇聚目标，对话/反应轴稳定，无人看镜头。
- 8：主要眼神正确，一方眼球角度略弱。
- 6：身体方向正确但精确关注点略含糊。
- 4：一人看错对象、穿轴或直视观众。
- 2：多人目光完全不相交。
- 0：眼神关系不存在。
- 硬失败：剧情依赖的关注目标看错，或反应镜头视线退出错误画面侧。

### 23. 口眼与微表情非对称 `micro_expression`

- 10：嘴角、眼睑、眉间、下颌和呼吸张力形成克制、非对称且符合情绪的表演。
- 8：情绪准确自然，只有一处略模板化。
- 6：表情能读懂但偏中性或常见“AI 悲伤/坚定脸”。
- 4：表情过度、僵硬或与剧情冲突。
- 2：五官各自表达不同情绪。
- 0：脸部表演不可用。

### 24. 近摄焦面、裁切与证据尺度 `macro_focus_crop` · gate

- 10：关键微特征/接触全部获得足够像素且落在焦内，裁切自然不截断因果链。
- 8：核心证据清晰，次要边缘略虚或略紧。
- 6：主体可读但一个关键细节接近分辨极限。
- 4：焦点错位、裁掉活动手/道具端点或景深切断接触。
- 2：近摄只剩漂亮纹理，无法理解动作。
- 0：关键对象不在画面。
- 硬失败：必需细节因裁切/虚焦无法验证。

### 25. 必需微特征存在、侧别与显著度 `required_microfeature` · gate

- 10：疤、泪膜、痣、刻痕等每项都存在、侧别正确、形态和强度符合描述，第一遍放大即可确认。
- 8：全部正确，一个特征略浅但仍可明确定位。
- 6：特征存在且侧别正确，但大小/对比接近不可辨。
- 4：特征落在错误侧、形态错误或缺少一项。
- 2：仅有随机纹理疑似对应。
- 0：全部微特征缺失。
- 硬失败：身份关键微特征缺失或左右颠倒。

### 26. 俯瞰地面拓扑与遮挡顺序 `overhead_ground_order` · gate

- 10：高机位下道路/区域拓扑、人物脚点、墙体高度、前后遮挡与尺度全部可反推。
- 8：地图关系准确，远端一处尺度略弱。
- 6：主地面成立，但一人脚点或墙体遮挡稍含糊。
- 4：人物像站在墙上、路径不连、重叠顺序错误。
- 2：画面像平面地图或微缩模型，失去空间高度。
- 0：俯瞰空间不可解释。
- 硬失败：角色占据错误地面/墙面，或分叉拓扑错误。

### 27. 关键证据未被裁切或遮挡 `evidence_survival` · gate

- 10：所有硬约束证据在最终 2D 图中清楚可见，无遮挡、虚焦、过曝或特效覆盖。
- 8：全部可验证，一个次要证据需放大查看。
- 6：核心证据都在，但至少一项接近判读下限。
- 4：一个硬约束虽可能生成了却无法确认。
- 2：多个关键证据被遮挡或裁掉。
- 0：无法审计源要求。
- 硬失败：任何决定故事逻辑的证据不可见。

## 2.4 新增严格物理维度

这些维度取代旧版笼统的 `physics_momentum`。评分时必须沿可见骨段、支撑点、兵器轴线和环境反馈逐段检查，不能因动作轮廓“有气势”而给高分。

### 28. 肩胛—肩—肘—腕运动链 `upper_limb_chain` · gate

- 10：双侧肩胛、肩峰、上臂、肘、前臂和腕的朝向连续，关节角度处于可实现范围，衣褶也支持其下方结构。
- 8：整条链可信，仅一处轮廓或衣料令关节定位略弱。
- 6：动作可以完成，但一个肩/肘/腕连接偏僵或接近活动范围极限。
- 4：一处骨段方向与相邻关节明显冲突，肘窝/腕面翻转，或手的位置无法由肩肘到达。
- 2：多段断裂、关节折叠或左右肢体融合。
- 0：无法解释为完整上肢。
- 严重物理失败：手臂结果位置无法通过画面中的肩—肘—腕链实现。

### 29. 躯干旋转与手臂姿势兼容性 `torso_limb_compatibility` · gate

- 10：胸廓、脊柱、骨盆、锁骨和双肩旋转属于同一个身体姿态，并为手臂动作提供合理空间。
- 8：整体兼容，仅腰肩扭转张力略弱。
- 6：姿态可实现，但胸廓或肩线有一处接近正面贴图式简化。
- 4：上半身朝向与手臂所需肩位冲突，胸廓像朝两个方向，或肩从躯干错误位置长出。
- 2：躯干和手臂像不同姿势拼接，出现不可能扭转。
- 0：上半身结构不可解释。
- 严重物理失败：R04 类“手臂局部看似成立、但与整个上半身不能同时成立”标为 critical；生产加权分保持原值，不执行封顶。

### 30. 重心、支撑面与脚底承重 `balance_support_load` · gate

- 10：重心投影落在动态支撑范围，承重脚完整着地，踝膝髋压缩、足底压力和地面接触影相互支持。
- 8：主要承重可信，仅非承重脚或接触影略轻。
- 6：姿态可维持，但重心偏边缘、膝髋压缩或足底压力较弱。
- 4：身体明显要倒、脚底悬浮/滑移、承重腿没有压缩，或地面反力方向错误。
- 2：无可信支撑面或多处腿脚承重矛盾。
- 0：违反基本重力。
- 严重物理失败：主体无任何可行支撑或承重脚与地面脱离。

### 31. 发力源与力传递路径 `force_path` · gate

- 10：可从脚底/骨盆看到发力，经核心旋转、肩臂或器械轴线连续传到精确接触点，沿途都有张力或压缩证据。
- 8：主力链完整，仅一段肌肉/衣褶响应略弱。
- 6：方向可读，但主要靠手臂，脚—核心—肩的连接缺乏一段证据。
- 4：武器已产生强接触结果，身体却是松弛站姿；力量在肩、腕或器械中途断掉。
- 2：身体与接触结果方向相反或多条力链互相冲突。
- 0：没有发力源，只有悬浮的结果姿势。
- 严重物理失败：接触结果需要显著冲量，但双方都没有任何可见发力或制动来源。

### 32. 作用力、反作用力与接触冲量 `reciprocal_force` · gate

- 10：双方接触面法线、兵器偏转、身体压缩/后坐、手腕抗扭和水花/尘土响应构成大小方向相容的一对力。
- 8：双方响应可信，仅一个次级反冲稍弱。
- 6：接触成立，但一方反作用不足或偏转角度略含糊。
- 4：一方显示强冲击而另一方完全不受力，或兵器接触角不可能产生画面中的偏转。
- 2：双方都向同一不合理方向受力，接触点与结果无因果关系。
- 0：武器相碰只是重叠，没有相互作用。
- 严重物理失败：接触发生但作用力—反作用力方向明确互斥。

### 33. 兵器刚性、轴线、数量与拓扑连续性 `prop_rigidity_topology` · gate

- 10：每件刚性兵器从柄到尖只有一条连续轴线，截面、长度、数量和遮挡前后完全一致，无融合或额外分支。
- 8：拓扑和轴线正确，仅透视缩短或边缘轻微不直。
- 6：兵器可工作，但一小段宽度/轴线有可见波动。
- 4：直枪/剑出现局部弯软、重复刃、错误连接或轻微 Y 形分叉。
- 2：兵器分叉、断裂、融合成多件或跨遮挡后换轴。
- 0：无法判断兵器是什么或有几件。
- 严重物理失败：R02 类“一根直枪变成 Y 字形”标为 critical；生产加权分保持原值，由独立交付规则拒绝而不是修改分数。

### 34. 衣发、水花、尘雾的因果响应 `secondary_motion_causality`

- 10：所有次级运动的方向、幅度、延迟和起点都能由主体速度、碰撞、风向或落点解释，并符合冻结时相。
- 8：主要反馈一致，仅一小束衣发/粒子略显装饰。
- 6：大方向正确，但反馈偏弱、过均匀或缺少局部起因。
- 4：衣发、水花或尘雾朝与动作无关方向运动，或在无接触处爆发。
- 2：多组效果各自采用不同风向和时相。
- 0：特效完全替代了物理几何。

### 35. 动作准备、刹停、受力与力量感 `motion_commitment` · gate

- 10：重心前置/后撤、关节预压、握持张力、肌肉/衣褶压缩和接触后的刹停共同表现明确重量与决心。
- 8：力量感强，仅一处预备或刹停反馈较弱。
- 6：动作方向清楚，但人物略像摆姿势，重量感只在部分身体出现。
- 4：兵器已经接触，双方仍像轻松站立；肘腕松、核心未参与、步幅和速度结果不匹配。
- 2：动作完全是静态陈列，接触与身体表演脱节。
- 0：没有要求的动作承诺。
- 严重物理失败：强碰撞结果与全身松弛状态并存，且无法解释为“极轻触碰”时标为 critical；生产加权分不封顶。

## 收敛后的刁钻审美审计

在分数连续三轮不再破新高后，对候选最佳图执行第二遍盲审：不看提示词和已有分数，分别以缩略图、100% 和 200% 检查轮廓、负空间、重复纹理、面部、手脚、材质交界、光影边缘和画面叙事。发现缺陷后：

1. 先尝试映射到现有维度并引用锚点；能映射则只补充该维度案例，不新建维度。
2. 只有同时满足“可直接观察、至少跨两张图复现、不能由现有维度解释、可通过提示词干预”四项，才新增维度。
3. 新维度必须补齐六档锚点、适用范围、是否 gate、与相邻维度的边界，并用全部历史图回测。
