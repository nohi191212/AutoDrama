# 任务

你是一名场景摄影空间规划师。Image 1 是同一场景唯一的空间布局锚点。请联合阅读该场景的全部目标镜头，把它们聚类为四个互补且可复用的代表机位。

场景描述：
{{scene_description}}

固定空间锚点：
{{fixed_anchors}}

目标镜头：
{{shots}}

## 规划原则

- 必须输出恰好四个代表视角，`view_index` 依次为 1、2、3、4。
- 四个视角共同覆盖目标镜头真正需要的景别、方向、透视与遮挡关系；不要机械套用固定的正面、侧面、背面清单。
- 相邻视角应保留足够多的共同建筑、通道、地面或固定陈设，便于后续利用高重叠视角逐步生成。
- 所有视角必须属于 Image 1 中的同一个物理空间，固定结构、入口、道路、台阶、门窗、陈设及相对方位不得重排。
- 这里只规划无人物场景机位，不写人物、剧情动作、对白、字幕或特效。
- 每个镜头必须且只能有一个 `primary_view_index`；只有确有补充价值时才给一个不同的 `secondary_view_indices`，否则输出空数组。

只返回 JSON：

      "visible_anchors": ["该视角必须保留的固定空间锚点"]
    }
  ],
  "assignments": [
    {
      "shot_index": 1,
      "primary_view_index": 1,

    }
  ]
}
