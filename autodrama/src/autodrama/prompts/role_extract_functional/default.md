# 任务

你是短剧角色资产规划助手。请在已抽取主要角色之外，从完整小说正文中抽取“功能角色”。

只输出功能角色，所有输出角色的 `role_tier` 必须是 `functional`。

# 输入

完整小说正文：
{{novel_full_context}}

主要角色列表：
{{primary_roles}}

已抽取功能角色列表：
{{functional_roles}}

# 判定顺序

先判断是否主要角色，再判断是否功能角色，最后判断是否背景存在。

如果某个人满足主要角色条件，即使在某场戏中只是传话、阻拦、递物、解释规则，也不要放入功能角色。

主要角色列表中的人物绝对不要重复输出，也不要换称谓输出。

# 功能角色定义

功能角色是不承担长期人物线、通常只服务于一个或少数场景，但有明确独立动作、对白、交互、信息传递、阻碍、引导、战斗、救治等功能的人。

判断核心：如果删除这个人，会导致某个镜头动作、对白、信息传递或事件触发变得不清楚，那么这个人就是功能角色。

满足任一条件即可归为功能角色：

- 有独立动作并推动当前场景。
- 有独立台词、喊话、传音、命令、警告。
- 与主要角色发生直接互动。
- 是镜头焦点的一部分，需要观众识别这个人正在做什么。
- 后续分镜需要引用这个具体身份。
- 该角色虽然短暂，但需要在多个镜头中保持基本外观或身份一致。

# 不要输出

- 主要角色列表中的任何人物。
- 只换称谓后的主要角色。
- 纯背景群体，例如游客们、围观者、众人、路人、工作人员们。
- 没有单独动作、没有单独台词、没有明确互动、只营造场面气氛的背景存在。
- 已抽取功能角色列表中已经出现的人物或身份。

# 无名功能角色命名

功能角色可以有名字，也可以无名。

无名功能角色必须使用“限定词 + 身份”命名，例如：

- 九尾狐密室游客甲
- 古殿机关守卫
- 黑衣保镖
- 检票员
- 传令弟子

不要使用“某人”“一个人”“路人”“众人”这类泛称。

# episode_key 规则

完整小说正文已按如下形式分段：

【episode_key: episode_001】

角色出现在哪个 episode_key 段落中，就把该 key 写入角色的 `episode_keys`。

只允许使用正文分段标题里真实出现的 episode_key。不要自造 key，不要使用中文章节名，不要输出空数组或 null。

# 视觉资产与多造型规则

输出的是功能角色的视觉资产根，不是每套衣服一个角色。

- 只抽当前完整小说正文中实际出镜、可视化出现，并且有独立动作、对白、互动、信息传递、阻碍或镜头功能的人物。
- 纯背景群体、气氛人群、无法识别个体的众人不要抽；复合称呼能拆成单人且各自有镜头功能时才拆。
- 同一自然人的称呼变化合并为一个角色，称呼放入 `aliases`；不要因为换装、受伤、脏污、湿透、破损等同脸同身形状态拆成多个角色。
- 无名功能角色命名必须具体到场景/身份/功能；编号角色如医生1/守卫1/游客甲如果有独立动作或台词，可以分别输出。
- `appearance_notes` 只写镜头识别所需的客观可画信息：服装、身份装束、体型、发型、持物、特殊标志或状态。

# appearance_assets 规则

每个功能角色也输出 `appearance_assets`。

- 默认至少输出 1 个 `name="base"`、`asset_role="base"` 的基础造型。
- 只有当正文明确出现同一功能角色的换装、受伤、血污、脏污、湿透、破损、伪装等状态，且后续分镜需要复用，才额外输出 `asset_role="variant"`。
- `variant` 的 `reference_asset_name` 通常填 `base`，表示后续出图应锁定同一脸、身形、发型基底，只改变服装/状态。
- 每个 appearance 的 `episode_keys` 只写该造型实际出镜或延续出现的 episode_key。
# 输出要求

只输出结构化 JSON。不要 Markdown，不要解释。

- 本轮只输出“已抽取功能角色列表”中尚未包含的新增功能角色。
- 如果没有新增功能角色，输出空 `roles`。
- `brief` 用一句话说明短期场景功能和与主要角色的互动。
- `appearance_notes` 只写分镜需要稳定识别的客观外观、身份装束、持物或动作特征。`appearance_assets` 写具体 base / variant 造型资产。
- `source_chapters` 只填写正文中明确出现的源章节范围；无法判断时留空数组。
- `has_dialogue` 表示此角色在正文中是否有明确对白、喊话、传音或命令。
- `visual_reuse_required` 只在该功能角色需要跨镜头保持稳定外观时为 true，否则为 false。
- 输出前自检：每个角色必须有非空 `name`、`role_tier="functional"`、非空 `episode_keys`。
