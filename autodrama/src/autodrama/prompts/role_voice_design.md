# 任务

根据角色基本设定和最终剧本，为每个角色设计可用于后续 TTS/音色生成的声音描述。

# 输入

标题：{{title}}

最终剧本：
{{final_script}}

角色设定：
{{roles}}

# 要求

- 每个主要角色至少生成 `normal` 音色。
- 如果剧本中存在明显情绪变化，可以为角色额外生成 `angry`、`sad`、`happy`、`tense`、`whisper` 或 `other`。
- `desc` 应该直接面向音色/TTS 模型，例如年龄感、性别感、音色、语速、情绪、咬字特点。
- `sample_text` 使用角色可能会说的一句短台词。
- 本节点只设计声音，不生成音频文件。
- 输出必须符合调用方提供的 JSON schema。
