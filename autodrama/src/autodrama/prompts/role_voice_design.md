# 任务

根据角色基本设定和最终剧本，为每个角色设计可用于后续 TTS/音色生成的声音描述。

# 输入

标题：{{title}}

最终剧本：
{{final_script}}

角色设定：
{{roles}}

# 要求

- `role_name` 必须填写角色设定中的 `name` 原文，例如“林浩”；不要填写角色 ID、字典键、`role_林浩` 这类内部标识。
- 每个主要角色至少生成 `normal` 音色。
- 如果剧本中存在明显情绪变化，可以为角色额外生成 `angry`、`sad`、`happy`、`tense`、`whisper` 或 `other`。
- `desc` 应该直接面向音色/TTS 模型，例如年龄感、性别感、音色、语速、情绪、咬字特点。
- `sample_text` 是后续声音设计/音色生成的参考文本，不是剧本对白。
- `sample_text` 必须使用第一人称，格式为“身份自我介绍 + 前期内心独白”，参考：
  “我是柯南，小学二年级学生。这不是一个普通的案件，真相永远只有一个。无论罪犯隐藏得多深，我都会用推理把他们找出来，揭露真相。这就是我的使命。”
- `sample_text` 建议 2-4 句，约 60-120 个中文字符，应体现角色身份、性格、语气和早期动机。
- `sample_text` 只能使用故事前期角色已经知道或会表达的信息，不要涉及后期关键剧情、最终反转、关键证据、结局、背叛真相或胜负结果。
- 如果是非 `normal` 情绪音色，`sample_text` 仍然保持“身份自我介绍 + 前期内心独白”，但语气要符合该情绪。
- 本节点只设计声音，不生成音频文件。
- 输出必须符合调用方提供的 JSON schema。
