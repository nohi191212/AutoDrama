# 任务

根据角色基本设定和分集剧情依据，为每个角色设计可用于后续 TTS/音色生成的声音描述。

# 输入

标题：{{title}}

分集剧情依据：
{{episode_stories}}

角色设定：
{{roles}}

# 要求

- `role_name` 必须填写角色设定中的 `name` 原文，例如“林浩”；不要填写角色 ID、字典键、`role_林浩` 这类内部标识。
- 一个角色最终只应绑定一个长期复用的官方 `voice_type`。本节点输出的多条 `role_voices` 不是多个候选音色，也不是为不同情绪选择不同人声；它们是同一基础声音在不同 `emotion` 下的声音需求、表演方式和试音文本。
- `role_tier=primary` 的主要角色至少生成 `normal` 基础声音需求条目。
- `role_tier=functional` 且 `has_dialogue=false` 的功能角色不要生成声音。
- `role_tier=functional` 且 `has_dialogue=true` 的功能角色只生成必要的基础声音需求，通常一个 `normal` 即可。
- 如果剧本中存在明显情绪变化，可以为角色额外生成 `angry`、`sad`、`happy`、`tense`、`whisper` 或 `other` 情绪表现条目。
- 不要选择具体 provider 音色，不要填写或编造 `voice_name`、`voice_type`、`voice_resource_id`、`voice_selection_reason`；这些字段应为空或 null。
- 具体官方音色由后续 `voice_select` 节点根据全局音色画像和试听样例决定，本节点只描述角色需要什么样的声音，且同一角色所有情绪会复用同一个官方 `voice_type`。
- 同一角色的不同情绪样例必须保持同一基础声音设定；情绪差异只体现在 `emotion`、`desc` 和 `sample_text` 中，不要改变年龄感、性别感、声线核心或写成另一种人声。
- `normal.desc` 应该直接面向音色/TTS 模型，描述稳定可长期复用的年龄感、性别感、音色、语速、咬字特点和常态表演方式。
- 非 `normal` 的 `desc` 只描述同一基础声音在对应情绪下的气息、语速、力度、停顿和情绪强度变化。
- `sample_text` 是后续声音设计/音色生成的参考文本，不是剧本对白。
- `sample_text` 必须使用第一人称，格式为“身份自我介绍 + 可说出口的前期目标/态度”，参考：
  “我是林舟，习惯把每个细节记清楚。越乱的时候，我越要冷静查下去。”
- `sample_text` 建议 1-2 句，约 30-45 个中文字符，应体现角色身份、性格、语气和早期动机，目标合成音频控制在 10 秒以内。
- `sample_text` 只能使用故事前期角色已经知道或会表达的信息，不要涉及后期关键剧情、最终反转、关键证据、结局、背叛真相或胜负结果。
- `sample_text` 必须像角色在试音时直接说出的一段话，不要写内心独白、心理活动、旁白说明或舞台提示；不要包含任何括号类字符，例如 `()`、`（）`、`[]`、`【】`、`{}`、`《》`。
- 如果是非 `normal` 情绪表现条目，`sample_text` 仍然保持“身份自我介绍 + 可说出口的前期目标/态度”，但语气要符合该情绪。
- 本节点只设计声音，不生成音频文件。
- 输出必须符合调用方提供的 JSON schema。
