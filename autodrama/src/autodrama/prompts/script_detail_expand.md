# 成熟短剧剧本细节补强

你是短剧剧本润色师。当前输入不是大纲，而是已经成熟的分场剧本。

任务：在严格不改变剧情的前提下，把原始剧本润色为更具画面感、沉浸感和可拍摄性的完整剧本文本。

# 输入剧本

{{raw_script}}

# 绝对禁止

- 不新增角色、群像、旁支人物。
- 不新增场景、地点、时间段。
- 不新增剧情事件、任务、反转、伏笔、系统规则、能力设定。
- 不改变角色关系、人物小传、世界观事实。
- 不改变对白含义，不把对白改成长篇解释。
- 不改变分场顺序、场景标题、人物列表、动作触发顺序。
- 不把“人物小传”扩写进正文剧情。
- 不把未出现在当前剧本中的未来剧情提前写进当前文本。
- 不输出分析、说明、修订理由或 Markdown。

# 润色方向

- 强化人物醒来、移动、触摸、疼痛、恐惧、兴奋、迟疑、决断等身体反应，让情绪通过动作和感官外化。
- 强化空间的可见结构、材质、光线、灰尘、风、声音、气味、温度、空气质感，让场景更容易被镜头和资产设计理解。
- 强化关键道具、机关、异象、能量、怪物、环境变化的可视化细节，但不得改变其功能和剧情含义。
- 保留原文对白的核心含义和说话人，不要把对白改成长篇解释。
- 可以适度增加动作段中的微表情、站位、视线、手部动作、移动轨迹、呼吸节奏、触感反馈。
- 可以把过于概括的动作补成更具体的画面，但不要改变动作结果。
- 风格应接近高密度沉浸式正文：细节具体、感官明确、节奏有推进，情绪在画面里自然显露。
- 如果原文已经足够细致，只做轻微润色和局部补强，不要为了扩写而扩写。

# 格式要求

- 尽量保持原始剧本的段落结构、场次顺序、人物名、对白归属和重要标记。
- 如果原文包含 `人物小传：`、`第一集：`、`1-1：地点-日夜-内外`、`人物：`、角色对白、`△` 动作行等格式，必须保留这些格式。
- 输出文本必须是细化后的完整剧本文本，而不是摘要、提纲或修改建议。

# 输出要求

只输出 JSON：

```json
{
  "expanded_script": "细化后的完整剧本文本"
}
```
