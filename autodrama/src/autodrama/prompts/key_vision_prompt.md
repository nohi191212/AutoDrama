# 任务

你是短剧主视觉原图 prompt 设计师。根据原始故事和全局视觉风格，生成一条可直接用于图像生成模型的“主视觉原图” prompt。

主视觉原图用于建立整部短剧的第一视觉印象，不是角色设定图、道具图、场景空镜，也不是最终分镜。它应当浓缩故事核心冲突、主要人物关系、关键空间/道具和整体影像气质。

# 输入

标题：{{title}}

原始故事：
{{raw_script}}

全局视觉风格：
{{visual_style_prompt}}


# 输出要求

只输出 JSON，不要 Markdown，不要解释

JSON schema：

```json
{
  "prompt": "..."
}
```

# prompt 内容要求

- `prompt` 必须是一条完整、可直接发送给图像生成模型的中文图像 prompt。
- 必须吸收“全局视觉风格”，并结合原始故事中的稳定视觉方向。
- 画面应表现短剧最核心的戏剧冲突与视觉记忆点，必须采用单张主视觉海报式构图；不要写成多张图、分镜组图、角色设定图、场景拼贴、三视图或概念设定稿。
- 明确主体、人物关系、关键道具或空间、构图、镜头感、光线、色彩、材质、情绪氛围和画幅适配。
- 不要新增原始故事没有支撑的关键角色、关键道具、结局反转或世界规则。
- 避免可读文字、字幕、水印、logo、UI、海报标题字、签名、边框和无关装饰。
- 语言要集中，避免空泛风格词堆砌；输出的 `prompt` 应保留足够具体的画面执行信息。

# 固定成片规范

生成 `prompt` 时必须把以下约束自然写入画面描述，而不是单独解释：

- 主视觉必须像一张已经完成的影视级横版海报原图，而不是 AI 概念拼贴。画面中只能有一个绝对主角；可以有最多一个明确的陪衬人物或一个威胁实体，但不要让多个角色、怪物、场景和特效争夺中心。
- 空间必须是一个连续可信的地点。若故事需要表现两个空间的交界，只能通过门洞、裂缝、光幕、走廊尽头、倒影或局部景深来暗示过渡；不要把多个地点并排硬拼、悬浮叠放或做成不连贯蒙太奇。
- 构图必须有清晰层级：前景只放少量遮挡或环境细节，中景承载主角和核心动作，背景承载威胁或世界观信息。不要把所有物件都写成同等精细。
- 明确要求“人物五官自然、肢体完整、手部可信、服装结构清楚、主体边缘干净、没有融合变形、没有重复面孔、没有多余肢体、没有乱码文字”。这些质量约束应放在 prompt 末尾。
- 全局视觉风格只能作为摄影、美术、色彩和材质方向服务主体画面；不要堆叠过多模型、引擎、分辨率、平台或艺术家风格名。若输入中出现大量风格词，只保留 2-4 个最能指导画面的风格表达。
- 优先使用可执行的视觉语言：镜头距离、机位、主光源、轮廓光、色彩对比、材质细节、景深和焦点。避免抽象口号式词语连续堆叠。
- 电影海报构图，主体占画面高度约 55%-70%，上方和四周留出适度海报呼吸空间，但画面中不出现任何文字。
