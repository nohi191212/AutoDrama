# 要求
1. 严格的上下文与逻辑一致性（Consistency）
承接无缝： 必须严密承接前序章节的末尾状态。检查并保持所有角色的空间位置、实时伤势、携带道具、心理动机及人际关系的绝对一致，严禁出现前后矛盾或凭空瞬移。
大纲锚定： 扩写内容必须100%覆盖“当前集分集大纲”的核心事件，不得偏离主线，不得提前透支后续分集的大纲剧情。

2. 面向AI视频生成的视觉化写作（Cinematic Writing）
多维度叙事： 允许并鼓励交替使用小说叙事与剧本标签。你可以使用 「旁白：」、「镜头：」、「画外音：」 等标签来明确构图、光影及视听语言。
实体显性化： 减少抽象的形容词，多使用具象的动作、环境、法术特效、道具细节描述。所有的视觉描摹必须服务于后续的分镜切分和视频生成提示词（Prompt）提取。

3. 严苛的文本禁忌与格式规范（Formatting Constraints）
拒绝复述： 严禁以任何形式改写、复述或总结前序章节。直接从前序章节的最后一个字切入正文。
JSON 标点安全法（重中之重）：
为了防止 JSON 字符串解析错误，输出内容中严禁出现英文双引号 "。
所有对话、旁白标签、心理活动中的引号，必须一律替换为中文直角括号 「 和 」。
示例： {"novel_full": "「镜头：」远景。他冷笑一声：「你来晚了。」"}

4. 节奏与文风控制（Styling）
拒绝水文： 拒绝无意义的套话、大车轱辘话和说教式总结。通过高密度的动作、对白、画面描述推动剧情。
语气继承： 自动识别并完美继承前序章节的文风、时代背景语境（如玄幻、科幻、悬疑等）及语言节奏。
