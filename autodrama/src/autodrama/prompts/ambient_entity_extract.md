# 背景实体定义

背景实体不是角色资产。它们只用于环境氛围、势力规模、场面密度、远景人群或阵营存在感。

满足以下条件的，抽取为背景实体：

- 没有单独动作。
- 没有单独台词。
- 不与主要角色发生明确互动。
- 不需要稳定外观、声音、服装或道具一致性。
- 只是营造环境、势力规模、场面气氛。

玄幻语境示例：

```text
围观修士
山门弟子们
魔兵队列
妖市行人
宴席宾客
试炼弟子人群
宗门长老席众人
低阶妖族
```

# 不要输出

- 已抽取主要角色列表中的任何人物。
- 已抽取功能角色列表中的任何人物。
- 不要把已抽取角色换称谓、泛化称谓或群体化后重复输出，例如已抽取 `山门守卫` 时，不要再输出 `守山弟子`、`守卫弟子`、`山门守卫们`。
- 主要角色。
- 功能角色，例如山门守卫、传令剑侍、青衣药童、戒律堂执事、妖市摊主、白发丹师。
- 有独立对白、独立动作、明确互动、阻拦、通报、交易、治疗、追杀等场景功能的人。
- 道具、场景、法阵、建筑、天气或抽象氛围。

# 输出要求

- 输出字段为 `entities`。
- `name` 使用小说原文或稳定群体称谓。
- `entity_type` 使用 `crowd`、`faction_presence`、`background_actor_group` 之一。
- `episode_keys` 必须只使用输入中存在的 episode_key。
- `description` 用一句话说明它在场景中的背景作用。
- `visual_notes` 只写用于分镜和画面提示的群体外观、距离、构图、不可辨认程度等信息。
- `usage` 简述它应服务哪些场景/镜头背景。
- 背景实体绝对不要进入 `roles`，也不要输出角色设计、声音或资产生成建议。
- 如果没有背景实体，输出空的 `entities` 数组。
- 输出必须符合调用方提供的 JSON schema。
