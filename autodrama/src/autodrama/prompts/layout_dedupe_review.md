# 要求

- 如果多个场景本质上是同一空间，只保留一个，并合并 `episode_keys`。
- 保留所有剧情需要的空间变化。
- 修正 `prompt`，保证所有场景都是可直接生图的无人物场景三视图设定板 prompt，并符合画面风格。每个 `prompt` 建议 260-460 个中文字符。
- 修正后的 `prompt` 必须明确“无人物场景三视图设定板”，并要求输出一张横向 16:9 资产设定图，画面分成三个并列视图：左侧顶视平面/空间动线图，中间正向主视/入口朝向立面图，右侧侧向或 45 度透视图。三个视图必须表现同一个空间、同一套固定结构、同一光源方向和同一材质设定，不能变成三个不同场景。
- 顶视平面图必须交代入口、窗/墙/柱/地面边界、主要家具或固定装置、角色可站位区域、摄影机可站位区域、剧情关键道具可摆放位置和行动动线。
- 正向主视图必须交代空间高度、前中后景层次、背景锚点、主视觉焦点、主要光源、墙面/天花/地面关系、重要装置和可供视频镜头复用的稳定构图。
- 侧向或 45 度透视图必须交代空间纵深、遮挡关系、可绕行路径、道具与人物站位的前后关系、材质厚度、反射/阴影和空气粒子状态。
- 修正后的 `prompt` 必须包含：画面风格要求、地点类型、昼夜/天气、空间结构、入口/窗/墙/地面/天花板关系、主要家具或固定装置、剧情关键道具可摆放的位置、材质纹理、色彩关系、主光来源、反射/阴影、环境粒子、9:16 短剧镜头可取景区域。
- 去重时不要丢失可复用空间锚点；如果合并两个相近场景，要把双方后续分镜需要的稳定区域、家具、出入口、可摆放道具表面合并进同一个 `desc` 和 `prompt`。
- 场景图不得出现人物、背影、手、剪影、人群、照片里的真人、海报人物、字幕、水印、文字标识；除非剧情明确需要，避免生成可读门牌、公司 logo 或屏幕文字。
- 不要把细致 prompt 压缩成“现代办公室、冷光、无人物”这类概括句。
- 不要把三视图写成三张独立图片；必须是一张图内三个并列视图，保持统一比例、统一美术风格、统一空间尺度。允许少量不可读的小标签或分区标题，但不要出现剧情文字、字幕、水印、logo、项目名、文件名或 ID。
- `merge_notes` 简短说明合并或未合并原因。
- 输出必须符合调用方提供的 JSON schema。
