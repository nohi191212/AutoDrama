# 输入

标题：{{title}}

当前场景：
{{layouts}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

# 要求

- 如果多个场景本质上是同一空间，只保留一个，并合并 `episode_keys`。
- 保留所有剧情需要的空间变化。
- 修正 `prompt`，保证所有场景都是可直接生图的无人物场景图 prompt，并符合画面风格。每个 `prompt` 建议 180-360 个中文字符。
- 修正后的 `prompt` 必须明确“无人物”，并包含：画面风格要求、地点类型、昼夜/天气、空间结构、入口/窗/墙/地面/天花板关系、前景/中景/背景层次、主要家具或固定装置、剧情关键道具可摆放的位置、材质纹理、色彩关系、主光来源、反射/阴影、环境粒子、镜头高度、镜头方向、焦段/景别、9:16 短剧构图适配。
- 去重时不要丢失可复用空间锚点；如果合并两个相近场景，要把双方后续分镜需要的稳定区域、家具、出入口、可摆放道具表面合并进同一个 `desc` 和 `prompt`。
- 场景图不得出现人物、背影、手、剪影、人群、照片里的真人、海报人物、字幕、水印、文字标识；除非剧情明确需要，避免生成可读门牌、公司 logo 或屏幕文字。
- 不要把细致 prompt 压缩成“现代办公室、冷光、无人物”这类概括句。
- `merge_notes` 简短说明合并或未合并原因。
- 输出必须符合调用方提供的 JSON schema。
