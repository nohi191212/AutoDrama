# 任务

为每个输入镜头编写一条中文空背景生图提示词。Image 1 是场景空间布局参考，用于理解地点的固定锚点、材质、空间结构、光线与整体风格；最终生图阶段还会由工作流提供对应的多视角母版。

场景描述：
{{scene_description}}

统一视觉质量：
{{visual_quality}}

镜头列表：
{{shots}}

# 输出

只返回 JSON。顶层键必须从 `background_1` 连续编号。每一项严格包含：

- `prompt_content`
- `shot_index`
- `description`

# 规则

- 每个输入镜头恰好输出一个背景项，每个 `shot_index` 恰好出现一次。
- `description` 使用一句简洁中文，供人工查看。
- `prompt_content` 使用中文，写成可直接执行的单幅电影级空背景提示词，不是摘要或分析。
- 以该镜头的 `video_prompt` 为开场构图和摄影机依据，提取开场视点、景别、角度、焦段感、视线方向及表演空间；不得另造不同机位。
- 明确描述当前视点能够看到的前景、中景、背景结构和遮挡关系，但不描述人物外观、动作或对白。
- 场景固定建筑、通行关系、地形、入口、台阶、道路、门窗、陈设、材质、天气、时间和主光方向属于同一个连续物理空间，不得为了单个镜头重排或重新设计。
- 保留与 Image 1 一致的光色基线，不得无依据地添加夕阳、金色时刻、暖琥珀色调或其他整体调色。
- 为镜头中的主体预留可信的空表演区、脚点、视线和运动空间，但背景本身不得出现人物、人体、身体部位、剪影、代理人或人物标记。
- 输入中的过肩、反打、主观等术语只供你在内部推断机位，不得原样写入 `prompt_content`。输出时只描述空画面中的机位高度、视线方向、景深和无具体形状的前景留白；`prompt_content` 不得出现人物、角色、主体、头部、肩背、身体轮廓、站立、对视、表演或动作，也不得用人物形遮挡物表达构图。
- 不生成等距地图、示意图、接触表、分屏、UI、标签、箭头、相机图标、注释、可读文字、字幕、logo 或水印。
