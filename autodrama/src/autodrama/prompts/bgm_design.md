# 任务

根据分集剧情依据设计可复用 BGM 清单。

# 输入

标题：{{title}}

分集剧情依据：
{{episode_stories}}

导演前期约束（重点参考情绪曲线、故事核心和每集节奏，不得改写剧情事实）：
{{director_prep}}

BGM数量：{{bgm_count}}

# 要求

- 必须正好生成 {{bgm_count}} 首 BGM，不要多生成，也不要少生成。
- 分集剧情依据来自 `script_novel_extract`，它是唯一剧情依据，不要假设还有额外压缩剧本。
- 导演前期约束只用于理解情绪曲线和音乐覆盖重点；如果它和分集剧情依据冲突，以分集剧情依据为准。
- BGM 清单应覆盖剧本主要情绪，例如悬疑推进、冲突升级、高潮反击、情感低落、温暖收束等；如果数量较少，优先覆盖最核心的情绪变化。
- `name` 要短，便于分镜引用。
- `mood` 写情绪标签。
- `prompt` 直接用于音乐生成模型，写音乐风格、节奏、乐器、情绪和使用场景。
- 不要生成完整歌词，默认生成无明确人声依赖的影视配乐描述。
- 输出必须符合调用方提供的 JSON schema。
