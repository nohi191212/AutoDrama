# 任务

根据用户提供的内容文本，规划完整剧集的总大纲和分集大纲。

# 输入

剧集概要：
{{raw_script}}

划分后的单集大致目标时长：{{episode_duration_seconds}} 秒

分集键名格式：episode_001, episode_002, ... episode_<三位数当前集索引>

# 参考输出格式

```json
{
  "outline": "剧情概要",
  "episode_outlines": {
    "episode_001": "第一集剧情",
    "episode_002": "第二集剧情",
    "episode_003": "第三集剧情"
  }
}
```

# 要求

- 由你根据剧情节奏、冲突推进和爽点位置自主分集。
- 如果“剧情大纲”是按“第1章、第2章……”编号的章节章纲，不是一定要参考这种划分，主要还是按照内容量和目标时长来划分。
- 如果你觉得故事内容很少，甚至可以只分1集、2集，还是那句话，按照内容量和时长进行划分。
- 每集目标时长约 {{episode_duration_seconds}} 秒。
- `outline` 写整体剧情概述，`episode_outlines` 写每一集的独立分集大纲。
- 剧情应当包含时间、地点、人物，发生了什么事情。剧情中出现的角色都需要有名字。
- 剧情要有清晰冲突、反转或爽点。
- 不要生成旁白。
- 输出必须符合调用方提供的 JSON Schema。
