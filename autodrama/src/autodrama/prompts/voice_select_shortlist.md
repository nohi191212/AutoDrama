# 任务

根据角色设计和全局音色画像，从候选音色中筛选最适合该角色的 top 5。

# 输入

角色设定：
{{role_design}}

候选音色画像：
{{voice_profiles}}

# 要求

- 只基于角色声音需求、身份、年龄感、性别呈现、性格和短剧对白自然度进行筛选。
- 使用 `voice_label` 给人读，使用 `voice_type` 作为唯一 provider 标识。
- 最多输出 5 个候选，按适配度从高到低排序。
- 每个候选的 `voice_type` 必须逐字复制候选音色画像中的值，不要翻译、缩写或自造。
- 警惕过强广告腔、客服腔、播音腔、动漫腔。
- 如果官方描述和画像冲突，优先相信画像。
- 输出必须符合调用方提供的 JSON schema。
