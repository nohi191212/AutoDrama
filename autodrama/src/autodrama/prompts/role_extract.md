# 任务

从全本完整小说中提取所有在剧情里出现的角色，并记录每个角色出现在哪些集和源章节中。

# 输入

标题：{{title}}

原始故事：
{{raw_script}}

完整小说正文（按集组织，每集可能包含“源章节：第X章-第Y章”等信息）：
{{novel_full}}

全集 episode_key 列表：{{episode_keys}}

画面风格：{{visual_style_label}}

画面风格要求：{{visual_style_prompt}}

# 要求

- 提取所有会在剧情中被看见、听见或明确参与事件的角色，包括主角、重要配角、反派、短暂出现但有动作/对白/剧情作用的小角色。
- `name` 必须沿用小说中的原名；只有确实没有名字但剧情需要后续生成时，才可以用身份称谓命名，例如“前台接待”“黑衣保镖”。
- 一个条目只能代表一个具体人物，不能把“路人”“众人”“保镖们”“员工们”这类群体当成角色；如果群体里有单独行动的人，应拆成具体人物或身份称谓。
- `episode_keys` 必须填写该角色实际出现或被明确提到并影响剧情的集，例如 `episode_001`。只能使用输入中存在的 episode_key。
- `source_chapters` 填写该角色出现的源章节范围或章节号，例如“第1章”“第3章-第5章”。如果正文只有分集没有源章节，则从该集开头的“源章节”信息推断；仍无法判断时填空数组。
- `importance` 用 `lead`、`main`、`supporting`、`minor`、`background` 之一：主角/核心对手为 `lead` 或 `main`，有明确剧情作用但戏份较少为 `supporting`，短暂推动事件为 `minor`，只为场面存在且无需后续设计为 `background`。
- `brief` 用一句话说明年龄感、身份、剧情功能，不要剧透后期反转。
- `aliases` 写小说中的别称、称呼、身份名；不要自造无依据别名。
- `appearance_notes` 只记录正文已经明确给出的稳定外观线索，例如年龄感、性别呈现、身形、发型、服装气质、标志物；没有就填空数组。
- 不要输出剧情梗概、分镜、道具清单或场景清单。
- 输出必须符合调用方提供的 JSON schema。
