# 任务

为 RightCode GPT-Image-2 生成道具参考图提示词。根据去重后的道具一句话介绍和导演预生成的 visual_tone，输出纯文字提示词。

这个节点只写提示词文字，不生成图片，不输出尺寸比例，不输出画幅词，不输出模型名称。

# 输入

去重后的道具介绍 generated_prop_intro：
{{generated_prop_intro}}

导演 visual_tone：
{{visual_tone}}

# 输出字段

- `prop_prompts`：对象，键必须与输入 `generated_prop_intro` 的道具名完全一致，值为对应道具的纯文字生图提示词。

# 要求

- 每个输入道具都必须输出一个提示词，不要新增输入中不存在的道具名。
- 提示词必须继承 `visual_tone`，但不要另行预设画面尺寸、画幅比例、横竖版、分辨率或固定模型名称。
- 不要出现 `16:9`、`9:16`、`1:1`、横向、竖向、portrait、landscape、asset sheet、三视图、设定板等尺寸或版式要求。
- 原道具提示词要强调主体轮廓、材质层次、光线逻辑、接触面和一眼可识别的结构细节，避免抽象形容词堆叠。
- 状态道具提示词要强调基于参考图保持结构一致，只做状态变化；变化文字要短而明确，适合图像编辑式生成。
- 默认无人物、无手持、无字幕、无水印、无 logo、无可读大段文字。
- 输出必须符合调用方提供的 JSON schema。
